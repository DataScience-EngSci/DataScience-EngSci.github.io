1. SVM Duality Synthesis & Support Vector Sparsity

Lecture 25 opens with the synthesis and resolution of Support Vector Machines (continuing SVM theory). Having established the primal optimization problem and the Karush-Kuhn-Tucker (KKT) conditions in Lecture 24, we complete the dual representation of the optimal margin classifier.

Recall the Wolfe Dual optimization problem for the separable margin classifier:

\[ \max_{\alpha} \quad \mathcal{W}(\alpha) = \sum_{i=1}^m \alpha_i - \frac{1}{2} \sum_{i=1}^m \sum_{j=1}^m y^{(i)} y^{(j)} \alpha_i \alpha_j \langle x^{(i)}, x^{(j)} \rangle \] \[ \text{subject to} \quad \alpha_i \ge 0 \quad \forall i \in \{1, \dots, m\}, \quad \text{and} \quad \sum_{i=1}^m \alpha_i y^{(i)} = 0 \]
Theorem 1.1 (The Sparsity of Support Vectors) From the KKT complementary slackness condition: \[ \alpha_i^* \left[ y^{(i)} \left( {w^*}^T x^{(i)} + b^* \right) - 1 \right] = 0, \quad \forall i = 1, \dots, m \] This implies an absolute dichotomy for every training example \(x^{(i)}\):
  1. Interior Points: If \(y^{(i)} \left( {w^*}^T x^{(i)} + b^* \right) > 1\) (the example lies strictly outside the canonical margin corridor), we must have \(\alpha_i^* = 0\).
  2. Boundary Points (Support Vectors): Only if \(y^{(i)} \left( {w^*}^T x^{(i)} + b^* \right) = 1\) (the point lies precisely on the canonical hyperplanes \(w^T x + b = \pm 1\)) can the Lagrange multiplier be strictly positive: \(\alpha_i^* > 0\).
Key Sparsity Result: The dual coefficients \(\alpha_i^*\) are strictly zero for all non-support points. Consequently, the optimal weight vector \(w^*\) is reconstructed as a sparse linear combination strictly of the support vectors (\(i \in \mathcal{S}\)):
\[ w^* = \sum_{i \in \mathcal{S}} \alpha_i^* y^{(i)} x^{(i)} \] where \(\mathcal{S} = \{i : \alpha_i^* > 0\}\) is the set of support vectors.

Consequently, to make a prediction on a novel test point \(x\), we evaluate:

\[ h_{\theta}(x) = g\left( {w^*}^T x + b^* \right) = g\left( \sum_{i \in \mathcal{S}} \alpha_i^* y^{(i)} \langle x^{(i)}, x \rangle + b^* \right) \]

Notice the computational triumph: even if the dataset consists of millions of examples (\(m = 10^6\)), if only \(|\mathcal{S}| = 25\) points reside on the margin, prediction depends solely on inner products with those 25 support vectors!

2. Regularization, Slack Variables & The Box Constraint

When data is non-linearly separable or contains noisy outliers, the hard margin constraints \(y^{(i)}(w^T x^{(i)} + b) \ge 1\) cannot be satisfied simultaneously. We introduce non-negative slack variables \(\xi_i \ge 0\) (Slides 16–19):

\[ \min_{w, b, \xi} \quad \frac{1}{2} \|w\|^2 + C \sum_{i=1}^m \xi_i \quad \text{s.t.} \quad y^{(i)}(w^T x^{(i)} + b) \ge 1 - \xi_i, \quad \xi_i \ge 0 \]

The parameter \(C > 0\) governs the relative weighting between maximizing the geometric margin (\(\frac{1}{\|w\|}\)) and penalizing margin violations.

Definition 2.1 (The Box Constraint in Wolfe Dual) Formulating the generalized Lagrangian with multipliers \(\alpha_i \ge 0\) and \(r_i \ge 0\): \[ \mathcal{L}(w, b, \xi, \alpha, r) = \frac{1}{2}\|w\|^2 + C \sum_{i=1}^m \xi_i - \sum_{i=1}^m \alpha_i \left[ y^{(i)}(w^T x^{(i)} + b) - 1 + \xi_i \right] - \sum_{i=1}^m r_i \xi_i \] Setting the partial derivative with respect to the slack variables to zero: \[ \frac{\partial \mathcal{L}}{\partial \xi_i} = C - \alpha_i - r_i = 0 \implies \alpha_i = C - r_i \] Since the Lagrange multiplier \(r_i \ge 0\), this forces \(\alpha_i \le C\). Combined with \(\alpha_i \ge 0\), we obtain the celebrated Box Constraint: \[ 0 \le \alpha_i \le C \quad \forall i \in \{1, \dots, m\} \] The dual objective function remains identical to the separable case, but the feasible domain for each dual multiplier is restricted to the closed interval \([0, C]\).
Parameter Correspondence: \(C \longleftrightarrow 1/\lambda\)
Comparing regularized Logistic Regression and soft-margin SVM reveals the reciprocal role of their tuning parameters: \[ C \longleftrightarrow \frac{1}{\lambda} \] A large \(C\) corresponds to small \(\lambda\) (strict margin enforcement, minimal tolerance for slack, low bias, high variance, risk of overfitting). A small \(C\) corresponds to strong regularization large \(\lambda\) (broad margin, high tolerance for misclassifications, high bias, low variance).

3. Canonical Kernels & Non-Linear Decision Boundaries

Replacing the inner product \(\langle x, z \rangle\) with an inner product in high-dimensional feature space \(\langle \phi(x), \phi(z) \rangle = K(x, z)\) allows SVMs to construct non-linear decision boundaries efficiently (Slides 20–22).

Definition 3.1 (Canonical Kernel Functions — Slide 22) Four primary kernels dominate modern machine learning implementations:
  1. Linear Kernel: \[ K(x, x') = \langle x, x' \rangle = x^T x' \] Used when features are already very high-dimensional (\(n \gg m\)).
  2. Polynomial Kernel: \[ K(x, x') = (\gamma \langle x, x' \rangle + r)^d \] where \(d \in \mathbb{N}\) is the polynomial degree, \(\gamma > 0\) is a scaling coefficient, and \(r \ge 0\) is the inhomogeneous intercept term.
  3. Gaussian Radial Basis Function (RBF) Kernel: \[ K(x, x') = \exp\left( -\gamma \|x - x'\|^2 \right) = \exp\left( -\frac{\|x - x'\|^2}{2\sigma^2} \right) \quad (\gamma > 0) \] Projects data into an infinite-dimensional reproducing kernel Hilbert space \(\ell_2\). Bandwidth parameter \(\gamma = \frac{1}{2\sigma^2}\) controls localization: large \(\gamma\) (small \(\sigma\)) creates narrow peaks (high variance), while small \(\gamma\) creates smooth global boundaries (high bias).
  4. Sigmoid (Hyperbolic Tangent) Kernel: \[ K(x, x') = \tanh\left( \gamma \langle x, x' \rangle + r \right) \] Originating from neural network theory; satisfies Mercer's condition only for certain restricted ranges of \(\gamma\) and \(r\).

4. Multi-Class Classification: One-vs-All (OvA)

SVM is intrinsically designed as a binary maximum-margin separator with \(y \in \{-1, +1\}\). In real-world applications (Slide 23), target labels span \(K > 2\) distinct categories: \(y \in \{1, 2, \dots, K\}\).

The standard approach presented in the slides is the One-vs-All (OvA) (also called One-vs-Rest):

  1. For each class \(k \in \{1, \dots, K\}\), train an independent binary SVM where training examples with label \(y^{(i)} = k\) are treated as positive (\(+1\)) and all other examples \(y^{(i)} \ne k\) are treated as negative (\(-1\)).
  2. This produces \(K\) parameter vectors and thresholds: \((\theta^{(1)}, b^{(1)}), \dots, (\theta^{(K)}, b^{(K)})\).
  3. To classify an unseen test input \(x_{\text{test}}\), compute the decision confidence score for all \(K\) models and select the class with the maximal score: \[ \hat{y}_{\text{test}} = \arg\max_{k \in \{1, \dots, K\}} h_\theta^{(k)}(x_{\text{test}}) = \arg\max_{k \in \{1, \dots, K\}} \left( (\theta^{(k)})^T x_{\text{test}} + b^{(k)} \right) \]

5. Practical Model Selection: Logistic Regression vs. SVM vs. Neural Networks

Slide 24 provides an invaluable engineering guide for practitioners choosing between Logistic Regression, Support Vector Machines, and Neural Networks based on the number of features \(n\) and the sample size \(m\):

Engineering Taxonomy (Slide 24) Let \(n\) be the number of features (\(x \in \mathbb{R}^{n+1}\)) and \(m\) be the number of training examples:
Regime Typical Dimensions Recommended Model Core Rationale
Large \(n\), Small \(m\) \(n \approx 10{,}000\), \(m \approx 10\dots 1{,}000\) Logistic Regression or Linear SVM (no kernel) With features far exceeding examples, linear decision boundaries are already expressive enough; complex non-linear kernels will severely overfit without additional signal.
Small \(n\), Intermediate \(m\) \(n \approx 1\dots 1{,}000\), \(m \approx 10\dots 10{,}000\) SVM with Gaussian (RBF) Kernel The feature space is low-dimensional, requiring non-linear feature expansion, but \(m\) is manageable enough for \(O(m^2)\) Gram matrix computation and quadratic programming.
Small \(n\), Very Large \(m\) \(n \approx 1\dots 1{,}000\), \(m \approx 50{,}000\dots 10^6+\) Manually engineer features + Logistic Regression / Linear SVM Gaussian SVM becomes computationally prohibitive (\(m \times m\) kernel matrix exceeds memory and quadratic programming slows down). Linear models on expanded features scale as \(O(m)\).

Note on Neural Networks: A multi-layer neural network is likely to perform well across all these regimes, but requires substantial hyperparameter tuning and is significantly slower to train compared to convex SVM solvers.

6. The Unsupervised Learning Paradigm & Clustering

Slide 25 marks the course's major conceptual pivot from Supervised Learning to Unsupervised Learning.

In supervised learning, every training instance arrives paired with a teacher signal: \(\{(x^{(1)}, y^{(1)}), \dots, (x^{(m)}, y^{(m)})\}\). In unsupervised learning (Slide 26–27), we are handed only an unlabelled collection of feature vectors:

\[ \mathcal{D} = \{x^{(1)}, x^{(2)}, \dots, x^{(m)}\}, \quad x^{(i)} \in \mathbb{R}^d \]

There are no target labels \(y^{(i)}\), no positive/negative annotations, and no error signals against ground truth. The goal is to uncover intrinsic, latent structure embedded within the data distribution.

Prominent Real-World Applications of Clustering (Slide 28):
  • Market Segmentation: Partitioning customer transaction databases into coherent behavioral cohorts for targeted marketing campaigns.
  • Social Network Analysis: Detecting communities, interest clusters, and densely connected cliques in graph networks.
  • Organizing Computing Clusters: Grouping server nodes and parallel processes to optimize data routing, load-balancing, and resource allocation.
  • Astronomical Data Analysis: Aggregating telescope observations and spectral measurements to identify galaxies, star formations, and interstellar phenomena.

7. The K-Means Clustering Algorithm & Geometry

The most foundational clustering technique is K-Means (Slides 29–40). Given an unlabelled dataset and an integer \(K\) specifying the desired number of clusters, K-Means seeks to position \(K\) cluster centers (centroids) \(\mu_1, \dots, \mu_K \in \mathbb{R}^d\) to minimize the total squared Euclidean distance from each sample to its nearest center.

Algorithm 7.1 (K-Means Clustering)
  1. Initialization: Initialize cluster centroids \(\mu_1, \mu_2, \dots, \mu_K \in \mathbb{R}^d\) randomly (typically by selecting \(K\) distinct training examples at random).
  2. Repeat until convergence:
    1. Cluster Assignment Step: For every sample \(i = 1, \dots, m\), compute its Euclidean distance to all \(K\) centroids and assign it to the closest centroid index \(c^{(i)}\): \[ c^{(i)} := \arg\min_{j \in \{1, \dots, K\}} \|x^{(i)} - \mu_j\|^2 \]
    2. Move Centroid Step: For every cluster index \(j = 1, \dots, K\), update \(\mu_j\) to be the arithmetic mean of all data points currently assigned to cluster \(j\): \[ \mu_j := \frac{\sum_{i=1}^m 1\{c^{(i)} = j\} x^{(i)}}{\sum_{i=1}^m 1\{c^{(i)} = j\}} \] Boundary condition: If a cluster \(j\) has zero assigned points (\(\sum 1\{c^{(i)} = j\} = 0\)), standard implementations either remove the cluster or reinitialize \(\mu_j\) to a randomly selected data point.

Slides 29 to 40 step through this process visually:

  • Step 0: Data points are initially unlabelled black dots in \(\mathbb{R}^2\). Two centroids (red \(\times\) and blue \(\times\)) are initialized arbitrarily.
  • Iteration 1 (Assignment): Points closer to the red \(\times\) are painted red; points closer to the blue \(\times\) are painted blue. The boundary separating the two clusters is the orthogonal bisector hyperplane between the two centroids (Voronoi cell partitioning).
  • Iteration 1 (Centroid Update): Red \(\times\) moves to the geometric center of all red dots; blue \(\times\) moves to the geometric center of all blue dots.
  • Iteration 2+: Points near the boundary flip colors as centroids migrate. Centroids adjust again. Within a few iterations, no points change cluster membership, and the centroids become completely stationary.

8. Clustering Non-Separated Data: The T-Shirt Sizing Case Study

A common misconception is that clustering is only applicable when data forms clearly separated islands. Slide 41 and Slide 52 demonstrate that K-Means is equally powerful for partitioning continuous, non-separated distributions.

Example 8.1 (T-Shirt Sizing — Slides 41 & 52) Consider a clothing manufacturer collecting physical measurements: Height vs. Weight across thousands of customers. The data forms a continuous bivariate cloud without isolated gaps.

The manufacturer wants to design standard apparel sizes:
  • If the business strategy produces \(K = 3\) sizes, K-Means segments the continuous distribution into Small (S), Medium (M), and Large (L). The resulting centroids \(\mu_S, \mu_M, \mu_L\) define the exact target proportions for pattern design.
  • If the company expands to \(K = 5\) sizes, running K-Means with \(K=5\) seamlessly segments the same population into Extra Small (XS), Small (S), Medium (M), Large (L), and Extra Large (XL).
Here, clustering serves not to discover pre-existing natural species, but to optimally quantize a continuous space for operational efficiency.

9. The Distortion Objective & Coordinate Descent Convergence Proof

Does K-Means always converge, or can it cycle infinitely between different cluster configurations? Slides 42–43 formalize the algorithm as an exact coordinate descent on an objective function known as the Distortion Function (or inertia).

Definition 9.1 (The Distortion Function \(J(c, \mu)\)) Let \(c = (c^{(1)}, \dots, c^{(m)})\) be the vector of cluster assignments, and \(\mu = (\mu_1, \dots, \mu_K)\) be the set of centroid vectors. The distortion cost is: \[ J(c, \mu) = \frac{1}{m} \sum_{i=1}^m \|x^{(i)} - \mu_{c^{(i)}}\|^2 \] \(J(c, \mu)\) measures the average squared Euclidean distance between each sample \(x^{(i)}\) and its assigned centroid \(\mu_{c^{(i)}}\).
Theorem 9.2 (K-Means as Coordinate Descent & Convergence Proof) The K-Means algorithm is exactly Coordinate Descent on \(J(c, \mu)\):
  1. Minimizing \(J\) with respect to \(c\) holding \(\mu\) fixed: \[ \min_{c^{(1)}, \dots, c^{(m)}} J(c, \mu) = \frac{1}{m} \sum_{i=1}^m \min_{c^{(i)} \in \{1, \dots, K\}} \|x^{(i)} - \mu_{c^{(i)}}\|^2 \] Because each term in the sum depends solely on a single assignment \(c^{(i)}\), the global minimum over \(c\) is obtained by minimizing each term independently: \[ c^{(i)} := \arg\min_{j \in \{1, \dots, K\}} \|x^{(i)} - \mu_j\|^2 \] This is precisely the Cluster Assignment Step!
  2. Minimizing \(J\) with respect to \(\mu\) holding \(c\) fixed: Holding cluster assignments fixed, we minimize the cost with respect to centroid \(\mu_j\). We group the terms belonging to cluster \(j\): \[ J_j(\mu_j) = \sum_{i: c^{(i)} = j} \|x^{(i)} - \mu_j\|^2 \] Taking the gradient with respect to \(\mu_j\) and setting it to zero: \[ \nabla_{\mu_j} J_j = \sum_{i: c^{(i)} = j} -2(x^{(i)} - \mu_j) = 0 \] \[ \sum_{i: c^{(i)} = j} x^{(i)} = \sum_{i: c^{(i)} = j} \mu_j = |S_j| \mu_j \implies \mu_j = \frac{\sum_{i: c^{(i)} = j} x^{(i)}}{|S_j|} \] where \(|S_j| = \sum_{i=1}^m 1\{c^{(i)} = j\}\). This is precisely the Move Centroid Step!
Monotonic Convergence Guarantee: Since each step strictly minimizes \(J\) along one set of coordinates, \(J(c, \mu)\) must monotonically decrease (or stay identical) at every iteration: \[ J(c^{(t+1)}, \mu^{(t+1)}) \le J(c^{(t+1)}, \mu^{(t)}) \le J(c^{(t)}, \mu^{(t)}) \] Because the number of distinct cluster assignments \(c \in \{1, \dots, K\}^m\) is finite (at most \(K^m\)), and each unique assignment uniquely defines the optimal centroids, K-Means cannot cycle infinitely. Therefore, K-Means is guaranteed to converge in a finite number of steps!

10. Random Initialization, Local Optima & Multiple Restarts

While coordinate descent guarantees convergence, the distortion surface \(J(c, \mu)\) is non-convex. Consequently, K-Means is susceptible to getting trapped in suboptimal local minima (Slides 44–48).

Pathologies of Bad Local Optima (Slide 47): Slide 47 illustrates two common failure modes when initial centroids are placed poorly:
  1. Cluster Splitting: Two initial centroids happen to fall into the same dense true cluster, causing it to be unnaturally cut in half, while two other distant clusters are forced to share a single centroid.
  2. Outlier Trapping: A centroid is initialized far away near an outlier or an empty region, leaving it isolated with very few points while the rest of the dataset is poorly clustered.

To prevent the algorithm from terminating in an inferior local minimum, we employ Multiple Random Restarts (Slide 48):

Algorithm 10.1 (Multiple Random Restarts K-Means — Slide 48) 
For i = 1 to 100 {
    1. Randomly initialize K-means: pick K distinct training examples {x^(r_1), ..., x^(r_K)} as initial centroids.
    2. Run K-means to convergence to obtain final assignments c and centroids μ.
    3. Compute distortion cost: J(c, μ) = (1/m) ∑ ||x^(i) - μ_{c^(i)}||^2.
}
Select the clustering configuration (c, μ) that achieved the lowest distortion cost J.

Rule of Thumb: Running 50 to 1000 restarts is computationally inexpensive and virtually guarantees escaping bad local minima when \(K\) is modest (\(K \in [2, 10]\)). When \(K\) is very large (hundreds of clusters), each random initialization often achieves comparable overall distortion.

11. Choosing the Number of Clusters \(K\): Elbow Method vs. Downstream Utility

How should an analyst choose the hyperparameter \(K\)? Unlike supervised learning, we cannot cross-validate on classification accuracy because there are no true labels (Slide 50).

Method 1: The Elbow Method (Slide 51) Compute the minimal distortion \(J\) across a range of cluster counts \(K \in \{1, 2, 3, \dots\}\) and plot \(J\) versus \(K\):
  • As \(K\) increases, \(J\) must monotonically decrease (at \(K = m\), every point is its own centroid and \(J = 0\)).
  • When the underlying data possesses genuine cluster structure, \(J\) drops sharply for small \(K\), and then levels off into a plateau.
  • The Elbow Point (the "kink" or inflection where the rate of decrease abruptly slows down) identifies the optimal \(K\). In Slide 51 (left graph), an unmistakable elbow appears at \(K = 3\).
Limitations of the Elbow Method: In many real-world datasets, the distortion curve decreases continuously and smoothly without any identifiable kink. In such settings, the elbow method is inconclusive, and \(K\) should be chosen based on downstream application metrics.
Method 2: Downstream Task Evaluation (Slide 52) In practice, clustering is rarely an end in itself; it is an intermediate representation for a downstream task. Therefore, \(K\) should be evaluated based on the performance metric of that subsequent application:
  • In the T-shirt manufacturing problem, choosing between \(K = 3\) (S, M, L) and \(K = 5\) (XS, S, M, L, XL) is not a question of clustering purity, but of business economics: does the revenue from better customer fit outweigh the additional inventory and manufacturing costs of two extra garment sizes?
  • In image compression, \(K\) is selected based on the target bit-rate versus reconstruction distortion (PSNR).

12. Bridge to Probabilistic Clustering: Mixture of Gaussians & EM Foundations

Slides 53–60 conclude Lecture 25 by introducing Mixture of Gaussians (GMM) and the Expectation-Maximization (EM) Algorithm, which form the direct bridge to Lecture 26.

Definition 12.1 (The Gaussian Mixture Generative Model — Slide 54) Suppose data \(\{x^{(1)}, \dots, x^{(m)}\}\) is generated by a mixture of \(k\) Gaussian components. We introduce a latent (hidden/unobserved) random variable \(z^{(i)}\) for each sample: \[ z^{(i)} \sim \text{Categorical}(\phi), \quad \text{where} \quad p(z^{(i)} = j) = \phi_j \quad \left(\phi_j \ge 0, \; \sum_{j=1}^k \phi_j = 1\right) \] \[ x^{(i)} \mid (z^{(i)} = j) \sim \mathcal{N}(\mu_j, \Sigma_j) \] The joint distribution of the observed feature \(x^{(i)}\) and latent component \(z^{(i)}\) is: \[ p(x^{(i)}, z^{(i)}) = p(x^{(i)} \mid z^{(i)}) p(z^{(i)}) \]

The parameters of the model are \(\theta = \{\phi_1, \dots, \phi_k, \; \mu_1, \dots, \mu_k, \; \Sigma_1, \dots, \Sigma_k\}\). To estimate them, we formulate the log-likelihood of our observed data (Slide 55):

\[ \ell(\phi, \mu, \Sigma) = \sum_{i=1}^m \log p(x^{(i)}; \phi, \mu, \Sigma) = \sum_{i=1}^m \log \left( \sum_{z^{(i)}=1}^k p(x^{(i)} \mid z^{(i)}; \mu, \Sigma) p(z^{(i)}; \phi) \right) \]
Connection to Gaussian Discriminant Analysis (GDA):
If the latent variables \(z^{(i)}\) were directly observable, Gaussian Mixture modeling would reduce to standard supervised Gaussian Discriminant Analysis (GDA), yielding closed-form Maximum Likelihood estimates:
\[ \phi_j = \frac{1}{m} \sum_{i=1}^m 1\{z^{(i)} = j\} \] \[ \mu_j = \frac{\sum_{i=1}^m 1\{z^{(i)} = j\} x^{(i)}}{\sum_{i=1}^m 1\{z^{(i)} = j\}} \] \[ \Sigma_j = \frac{\sum_{i=1}^m 1\{z^{(i)} = j\} (x^{(i)} - \mu_j)(x^{(i)} - \mu_j)^T}{\sum_{i=1}^m 1\{z^{(i)} = j\}} \]

However, because the \(z^{(i)}\) are latent (unobserved), the sum resides inside the \(\log\), preventing standard closed-form derivatives. This motivates the Expectation-Maximization (EM) Algorithm (Slides 57–60):

Algorithm 12.2 (The EM Algorithm for Gaussian Mixtures — Slides 58–59) Initialize \(\mu_j, \Sigma_j, \phi_j\) randomly. Repeat until convergence:
  1. E-Step (Expectation / Guess the Latent Variables):
    Using Bayes' theorem, compute the posterior probability (the responsibility or soft assignment) that sample \(x^{(i)}\) was generated by Gaussian component \(j\): \[ w_j^{(i)} := p(z^{(i)} = j \mid x^{(i)}; \phi, \mu, \Sigma) = \frac{p(x^{(i)} \mid z^{(i)} = j; \mu, \Sigma) \, p(z^{(i)} = j; \phi)}{\sum_{l=1}^k p(x^{(i)} \mid z^{(i)} = l; \mu, \Sigma) \, p(z^{(i)} = l; \phi)} \] where \(p(x^{(i)} \mid z^{(i)} = j; \mu, \Sigma) = \frac{1}{(2\pi)^{d/2}|\Sigma_j|^{1/2}} \exp\left(-\frac{1}{2}(x^{(i)}-\mu_j)^T \Sigma_j^{-1}(x^{(i)}-\mu_j)\right)\).
  2. M-Step (Maximization / Update Model Parameters):
    Update parameters via weighted sample averages using the soft weights \(w_j^{(i)}\): \[ \phi_j := \frac{1}{m} \sum_{i=1}^m w_j^{(i)} \] \[ \mu_j := \frac{\sum_{i=1}^m w_j^{(i)} x^{(i)}}{\sum_{i=1}^m w_j^{(i)}} \] \[ \Sigma_j := \frac{\sum_{i=1}^m w_j^{(i)} (x^{(i)} - \mu_j)(x^{(i)} - \mu_j)^T}{\sum_{i=1}^m w_j^{(i)}} \]
Conceptual Unification: K-Means vs. EM (Slide 60) Slide 60 highlights the profound structural analogy between K-Means and EM:
  • Hard vs. Soft Assignments: K-Means assigns each point deterministically to a single cluster (\(c^{(i)} \in \{1, \dots, K\}\) is hard). EM computes posterior probabilities (\(w_j^{(i)} \in [0, 1]\) is soft, expressing uncertainty in cluster boundaries).
  • Parameter Updates: K-Means moves centroids to the unweighted arithmetic mean of assigned points. EM updates Gaussian means and covariances as softly weighted averages.
  • Local Optima: Just like K-Means, EM converges monotonically to a local maximum of the incomplete log-likelihood, and is susceptible to initial placement. Multiple random restarts are standard practice.
In Lecture 26, we will prove that EM monotonically maximizes the Evidence Lower Bound (ELBO) via Jensen's Inequality, establishing the formal convergence theory for all latent variable models.
