1. From Hard Clustering to Soft Probabilistic Density Estimation

In Lecture 25, we explored K-Means clustering as a coordinate descent method minimizing the Euclidean distortion:

\[ J(c, \mu) = \frac{1}{m} \sum_{i=1}^m \|x^{(i)} - \mu_{c^{(i)}}\|^2 \]

While computationally efficient, K-Means enforces hard assignments: each training example \(x^{(i)}\) is deterministically allocated to a single centroid \(c^{(i)} \in \{1, \dots, K\}\). This presents two fundamental theoretical limitations:

  1. Zero Uncertainty Quantification: A sample equidistant between two cluster centers is assigned with \(100\%\) certainty to one of them, discarding boundary ambiguity.
  2. Spherical, Equal-Variance Geometry: The Euclidean metric implicitly assumes clusters are isotropic spheres with identical variance across all dimensions and components, failing on elongated, tilted, or unequal clusters.

Gaussian Mixture Models (GMMs) generalize K-Means into a fully generative probabilistic framework. Rather than a hard assignment, every data point receives a soft responsibility—a posterior probability vector over all \(K\) Gaussian components.

2. The Gaussian Mixture Generative Model & Latent Variables

Suppose we are given an unlabelled dataset \(\{x^{(1)}, x^{(2)}, \dots, x^{(m)}\}\) where \(x^{(i)} \in \mathbb{R}^d\) (Slide 2). We hypothesize that data points are generated by a mixture of \(k\) multivariate Gaussian distributions.

Definition 2.1 (The Generative Process — Slide 2) For each observation \(x^{(i)}\), we introduce a latent (hidden/unobserved) random variable \(z^{(i)} \in \{1, 2, \dots, k\}\) representing the cluster identity. The joint distribution factorizes as: \[ p(x^{(i)}, z^{(i)}) = p(x^{(i)} \mid z^{(i)}) \, p(z^{(i)}) \]
  1. Prior Distribution on Components: The latent variable follows a categorical distribution parameterized by \(\phi = (\phi_1, \dots, \phi_k)^T\): \[ z^{(i)} \sim \text{Categorical}(\phi), \quad \text{where} \quad p(z^{(i)} = j) = \phi_j \] subject to the simplex constraints: \(\phi_j \ge 0\) and \(\sum_{j=1}^k \phi_j = 1\).
  2. Conditional Density of Features: Conditioned on belonging to component \(j\), the feature vector is normally distributed: \[ x^{(i)} \mid (z^{(i)} = j) \sim \mathcal{N}(\mu_j, \Sigma_j) \] with mean \(\mu_j \in \mathbb{R}^d\) and covariance matrix \(\Sigma_j \in \mathbb{S}_{++}^d\): \[ p(x^{(i)} \mid z^{(i)} = j; \mu, \Sigma) = \frac{1}{(2\pi)^{d/2} |\Sigma_j|^{1/2}} \exp\left( -\frac{1}{2}(x^{(i)} - \mu_j)^T \Sigma_j^{-1}(x^{(i)} - \mu_j) \right) \]
The marginal density of the observed data point is obtained by summing (marginalizing) over all possible states of the latent indicator: \[ p(x^{(i)}; \phi, \mu, \Sigma) = \sum_{j=1}^k p(x^{(i)} \mid z^{(i)} = j; \mu_j, \Sigma_j) \, p(z^{(i)} = j; \phi) = \sum_{j=1}^k \phi_j \mathcal{N}(x^{(i)}; \mu_j, \Sigma_j) \]

3. The MLE Bottleneck & Supervised GDA Analogy

Given the parameters \(\theta = \{\phi, \mu, \Sigma\}\), the marginal log-likelihood across the \(m\) independent training samples is (Slide 3):

\[ \ell(\phi, \mu, \Sigma) = \sum_{i=1}^m \log p(x^{(i)}; \phi, \mu, \Sigma) = \sum_{i=1}^m \log \left( \sum_{z^{(i)}=1}^k p(x^{(i)} \mid z^{(i)}; \mu, \Sigma) \, p(z^{(i)}; \phi) \right) \]
The Analytical Bottleneck:
Notice the sum over \(z^{(i)}\) resides strictly inside the logarithm! When we differentiate \(\ell\) with respect to \(\mu_j\) or \(\Sigma_j\), the chain rule yields: \[ \nabla_{\mu_j} \log \sum_{l=1}^k \phi_l \mathcal{N}(x^{(i)}; \mu_l, \Sigma_l) = \frac{\phi_j \nabla_{\mu_j}\mathcal{N}(x^{(i)}; \mu_j, \Sigma_j)}{\sum_{l=1}^k \phi_l \mathcal{N}(x^{(i)}; \mu_l, \Sigma_l)} \] The denominator couples the parameters of all \(k\) components together. Setting \(\nabla \ell = 0\) produces a highly intractable, non-linear system with no closed-form algebraic solution!
The Supervised Benchmark: Connection to GDA (Slides 3 & 4)
Connection to Supervised GDA: In the hypothetical case where latent labels were observed, the model would reduce directly to Gaussian Discriminant Analysis.
If the latent labels \(z^{(i)}\) were known and observed (as in supervised Gaussian Discriminant Analysis from Lecture 18), the complete-data log-likelihood would decompose cleanly: \[ \ell_{\text{complete}}(\phi, \mu, \Sigma) = \sum_{i=1}^m \left[ \log p(x^{(i)} \mid z^{(i)}; \mu, \Sigma) + \log p(z^{(i)}; \phi) \right] \] Here, the logarithm directly hits the Gaussian exponential! Maximizing with respect to \(\phi_j, \mu_j, \Sigma_j\) yields the familiar closed-form MLE estimators (Slide 4): \[ \phi_j = \frac{1}{m} \sum_{i=1}^m 1\{z^{(i)} = j\} \] \[ \mu_j = \frac{\sum_{i=1}^m 1\{z^{(i)} = j\} x^{(i)}}{\sum_{i=1}^m 1\{z^{(i)} = j\}} \] \[ \Sigma_j = \frac{\sum_{i=1}^m 1\{z^{(i)} = j\} (x^{(i)} - \mu_j)(x^{(i)} - \mu_j)^T}{\sum_{i=1}^m 1\{z^{(i)} = j\}} \]

4. The EM Algorithm for Gaussian Mixtures (E-Step & M-Step)

Since \(z^{(i)}\) is unknown, the Expectation-Maximization (EM) algorithm establishes an elegant iterative compromise (Slides 5–8):

  1. E-Step (Expectation): Compute "soft guesses" (responsibilities) for the unknown \(z^{(i)}\) using the current parameter estimates.
  2. M-Step (Maximization): Re-estimate parameters using weighted maximum likelihood, replacing the hard indicators \(1\{z^{(i)}=j\}\) with the soft responsibilities \(w_j^{(i)}\).
Algorithm 4.1 (EM Algorithm for GMMs — Slides 6–7) Initialize \(\mu_j, \Sigma_j, \phi_j\) randomly for all \(j \in \{1, \dots, k\}\). Repeat until convergence:
  1. E-Step: For each training sample \(i \in \{1, \dots, m\}\) and cluster \(j \in \{1, \dots, k\}\), compute the posterior responsibility via Bayes' Rule: \[ w_j^{(i)} := p(z^{(i)} = j \mid x^{(i)}; \phi, \mu, \Sigma) = \frac{p(x^{(i)} \mid z^{(i)} = j; \mu, \Sigma) \, p(z^{(i)} = j; \phi)}{\sum_{l=1}^k p(x^{(i)} \mid z^{(i)} = l; \mu, \Sigma) \, p(z^{(i)} = l; \phi)} \] \[ w_j^{(i)} = \frac{\phi_j \mathcal{N}(x^{(i)}; \mu_j, \Sigma_j)}{\sum_{l=1}^k \phi_l \mathcal{N}(x^{(i)}; \mu_l, \Sigma_l)} \]
  2. M-Step: Update model parameters as weighted averages using weights \(w_j^{(i)}\): \[ \phi_j := \frac{1}{m} \sum_{i=1}^m w_j^{(i)} \] \[ \mu_j := \frac{\sum_{i=1}^m w_j^{(i)} x^{(i)}}{\sum_{i=1}^m w_j^{(i)}} \] \[ \Sigma_j := \frac{\sum_{i=1}^m w_j^{(i)} (x^{(i)} - \mu_j)(x^{(i)} - \mu_j)^T}{\sum_{i=1}^m w_j^{(i)}} \]
Comparison: K-Means vs. EM (Slide 8):
  • Hard vs. Soft Assignments: K-Means assigns \(c(i) \in \{1, \dots, K\}\) deterministically (hard). EM computes posterior probabilities \(w_j^{(i)} \in [0, 1]\) with \(\sum_j w_j^{(i)} = 1\) (soft).
  • Local Optima: Just like K-Means, EM is a non-convex optimization method susceptible to getting trapped in local maxima. Reinitializing with several different starting parameters (multiple random restarts) is essential in practice.

5. Mathematical Foundations: Jensen's Inequality

Slides 9 to 11 introduce the general theoretical framework justifying the EM algorithm. The fundamental mathematical bedrock is Jensen's Inequality.

Definition 5.1 (Convexity & Jensen's Inequality — Slide 10) Let \(f: \mathbb{R} \to \mathbb{R}\) be a function.
  • \(f\) is convex if \(f''(x) \ge 0\) for all \(x\). For vector-valued inputs \(f: \mathbb{R}^d \to \mathbb{R}\), the Hessian matrix is positive semi-definite: \(H \succeq 0\).
  • \(f\) is strictly convex if \(f''(x) > 0\) (or \(H \succ 0\)).
Theorem (Jensen's Inequality): Let \(f\) be a convex function, and let \(X\) be a random variable. Then: \[ E[f(X)] \ge f(E[X]) \] Moreover, if \(f\) is strictly convex, equality holds if and only if \(X = E[X]\) with probability 1 (i.e., \(X\) is a constant).
Geometric Intuition (Two-Point Distribution) Consider a discrete random variable taking values \(a\) and \(b\) with equal probability \(P(X = a) = 0.5\) and \(P(X = b) = 0.5\):
  • The expectation of \(X\) is the midpoint: \(E[X] = \frac{a + b}{2}\). Evaluating the function at the mean gives \(f(E[X]) = f\left(\frac{a+b}{2}\right)\), which lies on the convex curve.
  • The expected value of the function is the average of function values: \(E[f(X)] = \frac{f(a) + f(b)}{2}\), which lies on the secant chord connecting \((a, f(a))\) and \((b, f(b))\).
Because the secant chord of a convex curve always lies strictly above the curve itself, we have \(E[f(X)] \ge f(E[X])\).

Corollary for Concave Functions (e.g., Logarithm — Slide 14):
If \(g(x)\) is a concave function (\(g''(x) \le 0\)), such as \(g(x) = \log x\) whose second derivative is \(g''(x) = -\frac{1}{x^2} < 0\), the inequality reverses: \[ E[\log(X)] \le \log(E[X]) \]

6. The General EM Algorithm & The Evidence Lower Bound (ELBO)

We now formulate the general Expectation-Maximization theory for an arbitrary probabilistic model with observed data \(x\) and latent variables \(z\), parameterized by \(\theta\) (Slides 12–15).

Let \(\{x^{(1)}, \dots, x^{(n)}\}\) be a dataset of \(n\) independent training examples. The marginal log-likelihood is:

\[ \ell(\theta) = \sum_{i=1}^n \log p(x^{(i)}; \theta) = \sum_{i=1}^n \log \sum_{z^{(i)}} p(x^{(i)}, z^{(i)}; \theta) \]
Continuous Latent Variables: If \(z\) is continuous, the discrete summation over \(z\) is replaced by an integral: \(\int p(x, z; \theta) dz\).
Derivation of the Evidence Lower Bound (ELBO — Slides 13–15) Consider a single training example \(x\). Let \(Q\) be an arbitrary valid probability distribution over the latent variable \(z\) (\(\sum_z Q(z) = 1\) and \(Q(z) \ge 0\)). We multiply and divide by \(Q(z)\) inside the sum: \[ \log p(x; \theta) = \log \sum_z p(x, z; \theta) = \log \sum_z Q(z) \left( \frac{p(x, z; \theta)}{Q(z)} \right) \] Notice that \(\sum_z Q(z) \left[ \dots \right]\) is the definition of an expectation with respect to the distribution \(z \sim Q\): \[ \log p(x; \theta) = \log \left( E_{z \sim Q} \left[ \frac{p(x, z; \theta)}{Q(z)} \right] \right) \] Applying Jensen's inequality to the concave function \(f(u) = \log(u)\): \[ \log \left( E_{z \sim Q} \left[ \frac{p(x, z; \theta)}{Q(z)} \right] \right) \ge E_{z \sim Q} \left[ \log \left( \frac{p(x, z; \theta)}{Q(z)} \right) \right] \] \[ \log p(x; \theta) \ge \sum_z Q(z) \log \frac{p(x, z; \theta)}{Q(z)} \] We formally define this quantity as the Evidence Lower Bound (ELBO) (Slide 18): \[ \text{ELBO}(x; Q, \theta) = \sum_z Q(z) \log \frac{p(x, z; \theta)}{Q(z)} \] \[ \forall Q, \theta, x: \quad \log p(x; \theta) \ge \text{ELBO}(x; Q, \theta) \]

7. Derivation of ELBO Tightness: Why Posterior \(Q(z) = p(z|x)\)

For any arbitrary distribution \(Q\), the ELBO provides a lower bound on the true log-evidence. But when is this lower bound tight (i.e., when does equality hold)? (Slides 15–17)

Theorem 7.1 (Optimal Choice of \(Q\) — Slides 15–17) By Jensen's inequality, equality holds if and only if the random variable inside the expectation is constant with probability 1: \[ \frac{p(x, z; \theta)}{Q(z)} = c \] where \(c\) is a constant that does not depend on \(z\). This implies: \[ Q(z) \propto p(x, z; \theta) \] Since \(Q(z)\) is a probability distribution that must sum to 1 (\(\sum_z Q(z) = 1\)), we normalize: \[ Q(z) = \frac{p(x, z; \theta)}{\sum_{z'} p(x, z'; \theta)} = \frac{p(x, z; \theta)}{p(x; \theta)} = p(z \mid x; \theta) \] Conclusion: To make the lower bound tight at the current parameter value \(\theta\), we must set \(Q(z)\) equal to the posterior distribution of the latent variables given the observed data!
Direct Verification of Equality (Slide 17) We directly substitute \(Q(z) = p(z \mid x; \theta)\) into the lower bound: \[ \begin{aligned} \sum_z Q(z) \log \frac{p(x, z; \theta)}{Q(z)} &= \sum_z p(z \mid x; \theta) \log \frac{p(x, z; \theta)}{p(z \mid x; \theta)} \\ &= \sum_z p(z \mid x; \theta) \log \frac{p(z \mid x; \theta) p(x; \theta)}{p(z \mid x; \theta)} \\ &= \sum_z p(z \mid x; \theta) \log p(x; \theta) \\ &= \log p(x; \theta) \sum_z p(z \mid x; \theta) \\ &= \log p(x; \theta) \cdot 1 = \log p(x; \theta) \end{aligned} \] This confirms algebraically that setting \(Q\) to the true posterior makes the ELBO perfectly touch the true log-likelihood curve at \(\theta\).

8. Rigorous Proof of Monotonic Likelihood Convergence & Stopping Criteria

Slides 19–21 culminate in the general definition and convergence proof of the EM algorithm across the full dataset \(\{x^{(1)}, \dots, x^{(m)}\}\).

The General EM Algorithm (Slide 20) Repeat until convergence:
  1. E-Step: For each training example \(i \in \{1, \dots, m\}\), set: \[ Q_i(z^{(i)}) := p(z^{(i)} \mid x^{(i)}; \theta) \]
  2. M-Step: Update the parameters \(\theta\) by maximizing the sum of ELBOs: \[ \theta := \arg\max_\theta \sum_{i=1}^m \text{ELBO}(x^{(i)}; Q_i, \theta) = \arg\max_\theta \sum_{i=1}^m \sum_{z^{(i)}} Q_i(z^{(i)}) \log \frac{p(x^{(i)}, z^{(i)}; \theta)}{Q_i(z^{(i)})} \]
Local Optima: Because the incomplete-data log-likelihood \(\ell(\theta)\) is generally non-convex, EM converges to local maxima and is sensitive to initialization.
Monotonic Convergence Proof of the EM Algorithm Let \(\theta^{(t)}\) be the parameter estimate at iteration \(t\).
  1. In the E-step, setting \(Q_i^{(t)}(z^{(i)}) = p(z^{(i)} \mid x^{(i)}; \theta^{(t)})\) makes the bound tight: \[ \ell(\theta^{(t)}) = \sum_{i=1}^m \text{ELBO}\left(x^{(i)}; Q_i^{(t)}, \theta^{(t)}\right) \]
  2. In the M-step, \(\theta^{(t+1)}\) is explicitly chosen to maximize the bound holding \(Q^{(t)}\) fixed: \[ \theta^{(t+1)} = \arg\max_\theta \sum_{i=1}^m \text{ELBO}\left(x^{(i)}; Q_i^{(t)}, \theta\right) \] Therefore, the value of the ELBO evaluated at \(\theta^{(t+1)}\) cannot be smaller than at \(\theta^{(t)}\): \[ \sum_{i=1}^m \text{ELBO}\left(x^{(i)}; Q_i^{(t)}, \theta^{(t+1)}\right) \ge \sum_{i=1}^m \text{ELBO}\left(x^{(i)}; Q_i^{(t)}, \theta^{(t)}\right) = \ell(\theta^{(t)}) \]
  3. By Jensen's inequality, the true log-likelihood at \(\theta^{(t+1)}\) is always bounded from below by the ELBO evaluated with any distribution \(Q^{(t)}\): \[ \ell(\theta^{(t+1)}) \ge \sum_{i=1}^m \text{ELBO}\left(x^{(i)}; Q_i^{(t)}, \theta^{(t+1)}\right) \]
Chaining the inequalities together: \[ \ell(\theta^{(t+1)}) \ge \sum_{i=1}^m \text{ELBO}\left(x^{(i)}; Q_i^{(t)}, \theta^{(t+1)}\right) \ge \sum_{i=1}^m \text{ELBO}\left(x^{(i)}; Q_i^{(t)}, \theta^{(t)}\right) = \ell(\theta^{(t)}) \] \[ \implies \ell(\theta^{(t+1)}) \ge \ell(\theta^{(t)}) \] This establishes that the log-likelihood is monotonically non-decreasing at every iteration of EM!
Stopping Criterion The algorithm monitors the relative change in log-likelihood and terminates when progress falls below a convergence tolerance threshold \(\epsilon_{\text{th}}\): \[ \left| \frac{\ell(\theta)^{(t+1)} - \ell(\theta)^{(t)}}{\ell(\theta)^{(t)}} \right| < \text{th} \] Typical threshold values range from \(10^{-4}\) to \(10^{-6}\).
