1. Discrete Generative Learning & The Naive Bayes Classifier

In Lecture 18, we established the distinction between discriminative models (which directly model the conditional distribution \(p(y \mid x)\)) and generative models (which model the joint distribution \(p(x, y) = p(x \mid y) p(y)\) and invert it via Bayes' rule). While Gaussian Discriminant Analysis (GDA) handled continuous inputs \(x \in \mathbb{R}^d\), many foundational problems in machine learning involve discrete inputs—most notably natural language, document filtering, genomics, and discrete categorical attributes.

The Curse of Full Categorical Modeling Suppose each input vector \(x = [x_1, x_2, \dots, x_n]^T\) consists of \(n\) binary features, \(x_j \in \{0, 1\}\). If we model the class-conditional density \(p(x \mid y)\) as an unconstrained discrete multinomial distribution over all possible feature configurations: \[ |\{0, 1\}^n| = 2^n \text{ distinct outcomes} \] Specifying this distribution requires estimating \(2^n - 1\) independent parameters for each class! For a modest vocabulary of \(n = 50{,}000\) words in email spam filtering, \(2^{50{,}000}\) exceeds the number of elementary particles in the observable universe. Full parameterization is completely intractable.

To make high-dimensional discrete learning computationally and statistically tractable, we introduce the celebrated Naive Bayes assumption.

Definition 1.1 (The Naive Bayes Conditional Independence Assumption) The Naive Bayes model posits that the individual feature dimensions \(x_1, x_2, \dots, x_n\) are mutually conditionally independent given the class label \(y\): \[ p(x_1, x_2, \dots, x_n \mid y) = \prod_{j=1}^n p(x_j \mid y) \]
Why is it called "Naive"? In natural language and real-world data, features are notoriously correlated. For example, in an email containing the word "mortgage", the probability of observing the word "loan" is vastly higher than in a random email. The assumption that words appear independently of one another given the spam label is demonstrably false. Nonetheless, in practice, Naive Bayes often performs extraordinarily well because classification depends only on the argmax of the posterior odds rather than calibrated probabilities!
Parameter Complexity Reduction

Under the Naive Bayes assumption, instead of modeling all \(2^n\) configurations simultaneously, we only need to estimate the univariate marginal parameters for each feature:

\[ \phi_{j \mid y=1} = p(x_j = 1 \mid y = 1), \quad \phi_{j \mid y=0} = p(x_j = 1 \mid y = 0), \quad \phi_y = p(y = 1) \]

For \(n\) binary features and binary classification \(y \in \{0, 1\}\), the total parameter count drops exponentially from \(2^n - 1\) to:

\[ 2n + 1 \text{ parameters} \]

(Conditional Independence: Conditioned on class \(y\), features \(X_1, \dots, X_n\) are statistically independent \(\implies\) parameter complexity is \(\mathcal{O}(n)\), requiring only \(2n+1\) parameters).

2. Text Classification (Spam Filtering) & Analytical MLE

Consider building an email spam filter. We compile an indexed vocabulary dictionary containing \(n\) words:

\[ \text{Dictionary} = [\text{a}, \dots, \text{aardvark}, \dots, \text{buy}, \dots, \text{discount}, \dots, \text{viagra}, \dots, \text{zyzzyva}]^T \]

Each incoming email message is encoded as a binary vector \(x \in \{0, 1\}^n\), where:

\[ x_j = \mathbf{1}\{\text{word } j \text{ appears in the email}\} \]
Theorem 2.1 (Maximum Likelihood Estimates for Multivariate Bernoulli Naive Bayes) Given \(m\) independent training samples \(\{(x^{(i)}, y^{(i)})\}_{i=1}^m\) where \(y^{(i)} \in \{0, 1\}\), the joint log-likelihood of the dataset is: \[ \ell(\phi) = \sum_{i=1}^m \ln p(x^{(i)}, y^{(i)}) = \sum_{i=1}^m \left[ \sum_{j=1}^n \ln p(x_j^{(i)} \mid y^{(i)}) + \ln p(y^{(i)}) \right] \] Substituting the Bernoulli parameterizations \(p(x_j \mid y) = \phi_{j \mid y}^{x_j} (1 - \phi_{j \mid y})^{1 - x_j}\) and \(p(y) = \phi_y^y (1 - \phi_y)^{1 - y}\), maximizing \(\ell(\phi)\) with respect to each parameter yields closed-form empirical counting solutions: \[ \phi_{j \mid y=1} = \frac{\sum_{i=1}^m \mathbf{1}\{x_j^{(i)} = 1 \land y^{(i)} = 1\}}{\sum_{i=1}^m \mathbf{1}\{y^{(i)} = 1\}} \] \[ \phi_{j \mid y=0} = \frac{\sum_{i=1}^m \mathbf{1}\{x_j^{(i)} = 1 \land y^{(i)} = 0\}}{\sum_{i=1}^m \mathbf{1}\{y^{(i)} = 0\}} \] \[ \phi_y = \frac{\sum_{i=1}^m \mathbf{1}\{y^{(i)} = 1\}}{m} \]

(Interpretation: \(\phi_{j \mid y=1}\) represents the empirical fraction of spam emails containing word \(j\)).

To classify a newly arrived test email \(x_{\text{test}}\), we apply Bayes' rule to compute the posterior class probability:

\[ p(y = 1 \mid x_{\text{test}}) = \frac{p(x_{\text{test}} \mid y = 1) p(y = 1)}{p(x_{\text{test}})} = \frac{\left( \prod_{j=1}^n p(x_j \mid y=1) \right) p(y=1)}{\left( \prod_{j=1}^n p(x_j \mid y=1) \right) p(y=1) + \left( \prod_{j=1}^n p(x_j \mid y=0) \right) p(y=0)} \]

The decision rule predicts spam whenever \(p(y = 1 \mid x_{\text{test}}) > 0.5\), or equivalently when the log-odds ratio is positive:

\[ \ln \frac{p(y = 1 \mid x_{\text{test}})}{p(y = 0 \mid x_{\text{test}})} = \sum_{j=1}^n \ln \frac{p(x_j \mid y=1)}{p(x_j \mid y=0)} + \ln \frac{p(y=1)}{p(y=0)} > 0 \]

3. Feature Extensions & Laplace Add-One Smoothing

Generalizing to Categorical Features

What if an input feature is discrete but can take on \(k_j\) discrete levels instead of being binary, \(x_j \in \{1, 2, \dots, k_j\}\)?

Generalization to Discrete Multi-Valued Features: If feature \(x_j\) takes values in a discrete set \(\{1, \dots, k_j\}\) rather than \(\{0, 1\}\), we replace the Bernoulli likelihood with a Categorical (Multinomial) distribution: \[ p(x_j = l \mid y = c) = \phi_{j, l \mid y=c}, \quad \text{with } \sum_{l=1}^{k_j} \phi_{j, l \mid y=c} = 1 \]

Handling Continuous Features: Discretization & KDE

If features are continuous (e.g. house area, temperature), two standard approaches exist within the Naive Bayes framework:

  1. Discretization / Binning: Discretize the continuous domain into bins (e.g. Area: \(50\text{--}60\,\text{m}^2 \to \text{Bin } 1\), \(60\text{--}70\,\text{m}^2 \to \text{Bin } 2\), etc.), reducing the problem back to categorical Naive Bayes.
  2. Gaussian Naive Bayes (or KDE): Model each continuous feature as a 1D univariate normal distribution \(x_j \mid y = c \sim \mathcal{N}(\mu_{jc}, \sigma_{jc}^2)\). Notice that unlike GDA (which fits a full \(d \times d\) covariance matrix), Gaussian Naive Bayes strictly forces the covariance matrix to be diagonal: \(\Sigma = \text{diag}(\sigma_1^2, \dots, \sigma_d^2)\).

The Zero-Frequency Pathology & Laplace Smoothing

Suppose an incoming email contains an unusual word that never appeared in any training email (for example, "Naimark"). Under standard MLE:

\[ \phi_{\text{Naimark} \mid y=1} = \frac{0}{\sum \mathbf{1}\{y=1\}} = 0, \quad \phi_{\text{Naimark} \mid y=0} = \frac{0}{\sum \mathbf{1}\{y=0\}} = 0 \]

When evaluating the class-conditional probability product:

\[ p(x \mid y) = \prod_{j=1}^n p(x_j \mid y) = \dots \times 0 \times \dots = 0 \]

The posterior probability becomes an indeterminate \(\frac{0}{0}\)! Even if every single other word in the email screamed "SPAM" with overwhelming certainty, that single zero completely obliterates all accumulated evidence.

Theorem 3.1 (Laplace Add-One Smoothing) To guarantee non-zero probabilities, we inject uniform pseudo-counts (equivalent to a uniform Dirichlet / Beta prior). For a binary feature: \[ \phi_{j \mid y=1} = \frac{\sum_{i=1}^m \mathbf{1}\{x_j^{(i)} = 1 \land y^{(i)} = 1\} + 1}{\sum_{i=1}^m \mathbf{1}\{y^{(i)} = 1\} + 2} \] More generally, for any discrete random variable taking on \(k\) distinct categories: \[ p(z = l) = \frac{\text{count}(z = l) + 1}{\sum_{j=1}^k \text{count}(z = j) + k} \]

(Multi-Class Laplace Smoothing: For a \(k\)-ary feature, add \(1\) to the numerator and \(k\) to the denominator).

This ensures \(\phi > 0\) everywhere, eliminates numerical crashes, and asymptotically converges to the true empirical frequency as sample size \(m \to \infty\).
Modern Generative Paradigms: Slide 10 emphasizes that while Naive Bayes represents the foundational discrete generative model, modern deep generative learning encompasses GANs (Generative Adversarial Networks) and VAEs (Variational Autoencoders), which model complex, high-dimensional distributions without restrictive independence assumptions.

4. Bayesian Parameter Estimation & Uncertainty Modeling

Up to this point, our estimation philosophy has been strictly frequentist: the parameter \(\theta\) is viewed as a fixed, unknown constant, and we sought a point estimate \(\hat{\theta}_{\text{MLE}}\) that maximized the likelihood of observed data.

In the Bayesian philosophy, parameter uncertainty is explicitly modeled by treating \(\theta\) as a random variable governed by a probability distribution.

The Bayesian Update Equation Given a prior distribution \(p(\theta)\) encapsulating our initial beliefs before seeing the dataset, and a likelihood \(p(y \mid X, \theta) = \prod_{i=1}^m p(y^{(i)} \mid x^{(i)}, \theta)\), Bayes' theorem computes the full posterior distribution over parameters: \[ p(\theta \mid X, y) = \frac{p(y \mid X, \theta) p(\theta)}{p(y \mid X)} = \frac{\prod_{i=1}^m p(y^{(i)} \mid x^{(i)}, \theta) p(\theta)}{\int_\theta \prod_{i=1}^m p(y^{(i)} \mid x^{(i)}, \theta) p(\theta) \, d\theta} \]
Entropy Reduction & Posterior Computation
In high-dimensional models, the posterior distribution over parameters is rarely available in closed form and must be approximated:
  1. Numerical / Sampling Methods: Markov Chain Monte Carlo (MCMC) and Gibbs Sampling.
  2. Analytical Approximations: Variational Inference (VI).
Typically, the prior distribution is chosen to be diffuse (uniform or high-variance Gaussian), representing high initial entropy (uncertainty): \[ \text{Entropy} = \mathbb{E}[-\ln p(\theta)] = \langle -\ln p(\theta) \rangle \] Conditioning on evidence \((x^{(i)}, y^{(i)})\) concentrates probability mass, yielding a posterior distribution for \( heta\) with substantially reduced entropy whose mode defines \( heta_{\text{MAP}}\).

Prediction: Point Estimation vs. Fully Bayesian Integration

How do we predict the output \(y_{\text{test}}\) for an unseen input \(x_{\text{test}}\)? (Slide 13):

  • MAP Point Estimate: Choose the single parameter vector that maximizes posterior density: \[ \theta_{\text{MAP}} = \arg\max_\theta p(\theta \mid X, y) \implies y_{\text{test}} = \arg\max_y p(y \mid x_{\text{test}}, \theta_{\text{MAP}}) \]
  • Fully Bayesian Prediction: Instead of committing to a single \(\theta_{\text{opt}}\), marginalize across all possible parameter values, weighting each model by its posterior probability: \[ p(y \mid x_{\text{test}}, X, y) = \int_\theta p(y \mid x_{\text{test}}, \theta) p(\theta \mid X, y) \, d\theta \] \[ y_{\text{test}} = \arg\max_y \int_\theta p(y \mid x_{\text{test}}, \theta) p(\theta \mid X, y) \, d\theta \]

5. MAP Estimation, Regularization & Conjugate Priors

Bayesian Linear Regression Derivation

Let us work out the analytical posterior distribution for linear regression (Slides 14–15):

\[ y = X\theta + \epsilon, \quad \epsilon \sim \mathcal{N}(0, I) \implies p(y \mid X, \theta) \propto \exp\left(-\frac{1}{2}(y - X\theta)^T (y - X\theta)\right) \]

Assume a Gaussian prior over the parameters:

\[ \theta \sim \mathcal{N}(\mu_0, \Lambda_0), \quad \Lambda_0 = \text{diag}(\lambda_0) \implies p(\theta) \propto \exp\left(-\frac{1}{2}(\theta - \mu_0)^T \Lambda_0^{-1} (\theta - \mu_0)\right) \]

The posterior density is proportional to the product of likelihood and prior:

\[ p(\theta \mid X, y) \propto p(y \mid X, \theta) p(\theta) \propto \exp\left(-\frac{1}{2} \left[ (y - X\theta)^T(y - X\theta) + (\theta - \mu_0)^T \Lambda_0^{-1} (\theta - \mu_0) \right]\right) \]

Completing the square in the quadratic exponent proves that the posterior is also Gaussian:

\[ p(\theta \mid X, y) = \mathcal{N}(\mu_m, \Lambda_m) \]
Theorem 5.1 (Posterior Parameters for Bayesian Linear Regression) \[ \Lambda_m = \left( X^T X + \Lambda_0^{-1} \right)^{-1} \] \[ \mu_m = \Lambda_m \left( X^T y + \Lambda_0^{-1} \mu_0 \right) \]
Connection to Ridge Regression Normal Equations (Bayesian Interpretation):
Suppose we set a zero-mean isotropic prior \(\mu_0 = 0\) and covariance \(\Lambda_0 = \frac{1}{\alpha} I\) (so \(\Lambda_0^{-1} = \alpha I\)). Then the posterior mean becomes: \[ \mu_m = \left( X^T X + \alpha I \right)^{-1} X^T y \] This is identical to the Ridge Regression Normal Equation! Since the posterior is a symmetric bell-shaped Gaussian, its mode equals its mean: \[ \theta_{\text{MAP}} = \arg\max_\theta p(\theta \mid X, y) = \mu_m \]

The Fundamental Equivalence: MAP as Regularization

Taking the log of the posterior objective (Slides 16–17):

\[ \theta_{\text{MAP}} = \arg\max_\theta \left[ \ln p(y \mid X, \theta) + \ln p(\theta) \right] \]

The prior term \(\ln p(\theta)\) acts directly as the regularization penalty!

  • Gaussian Prior: \(p(\theta) \sim \mathcal{N}\left(0, \frac{1}{\lambda} I\right) \implies \ln p(\theta) = -\frac{\lambda}{2} \|\theta\|_2^2 + \text{const}\), generating \(L_2\) Ridge Regularization (Smoothness).
  • Laplace Prior: \(p(\theta) \propto \exp\left(-\lambda \|\theta\|_1\right) \implies \ln p(\theta) = -\lambda \|\theta\|_1 + \text{const}\), generating \(L_1\) Lasso Regularization (Sparsity).
Bias-Variance Insight (Regularization Perspective):
Compared to unconstrained Maximum Likelihood (which places zero prior constraint on \( heta\)), the MAP estimator acts as an informative prior that substantially reduces estimator variance at the cost of a slight increase in bias, providing a Bayesian foundation for regularization to prevent overfitting.

The Concept of Conjugate Priors

In general Bayesian inference, computing the normalizing denominator \(\int p(y \mid X, \theta) p(\theta) d\theta\) requires solving an intractable high-dimensional integral. A prior is called a conjugate prior for a likelihood family if the resulting posterior distribution belongs to the exact same functional family as the prior (Slide 18).

Conjugate Prior Pairs
  • Gaussian Likelihood + Gaussian Prior \(\implies\) Gaussian Posterior: Normal is self-conjugate.
  • Poisson Likelihood + Gamma Prior \(\implies\) Gamma Posterior: Gamma is conjugate for Poisson.
  • Bernoulli Likelihood + Beta Prior \(\implies\) Beta Posterior: Beta is conjugate for Bernoulli.
  • Multinomial Likelihood + Dirichlet Prior \(\implies\) Dirichlet Posterior: Dirichlet is conjugate for Multinomial.
With conjugate priors, posterior inference requires zero numerical integration—we simply update the algebraic hyper-parameters!

6. Motivation for Neural Networks & The "One Learning Algorithm" Hypothesis

Linear models, logistic regression, and Naive Bayes are fundamentally constrained by linear decision boundaries (or fixed feature transformations). When data is non-linearly separable, classical machine learning relied on handcrafted polynomial features.

Failure of Handcrafted Polynomial Expansions in High Dimensions Suppose we have \(n = 100\) tabular features (\(x_1 = \text{size}, x_2 = \text{\# bedrooms}, \dots\)). To learn a non-linear quadratic boundary, we include all pairwise cross-terms: \[ g\left(\theta_0 + \sum_{i=1}^n \theta_i x_i + \sum_{i=1}^n \sum_{j \ge i}^n \theta_{ij} x_i x_j + \dots\right) \] The number of quadratic terms is \(\approx \frac{n^2}{2} \approx 5{,}000\).

Now consider a tiny computer vision task: classifying a small \(50 \times 50\) RGB car image (Slide 21): \[ 50 \times 50 \text{ pixels} \times 3 \text{ channels (RGB)} = 7{,}500 \text{ features} \] The number of pairwise features \(x_i x_j\) explodes to: \[ \frac{(7{,}500)^2}{2} \approx 28{,}125{,}000 \text{ features} \implies \approx 3\text{M} \text{ to } 28\text{M parameters!} \] Handcrafting non-linear features in raw sensory spaces (images, audio, video) leads to an insurmountable parameter explosion and disastrous overfitting. We need models that learn their own non-linear feature representations automatically.

The "One Learning Algorithm" Hypothesis

In Slides 22–23, the course highlights revolutionary neurobiology experiments (e.g. Metin & Frost, 1989; Roe et al., 1990) exploring the auditory and somatosensory cortex:

Biological Rewiring Experiments When scientists surgically disconnected the visual inputs from the visual cortex and re-routed optic nerve signals directly into the auditory cortex, the auditory tissue did not fail—instead, the auditory cortex learned to see!

Similarly, re-routing optic signals into the somatosensory cortex resulted in the somatosensory cortex learning to process vision.

Implication: The human neocortex does not run hundreds of specialized, hardcoded algorithms for hearing, seeing, and touch. Instead, the brain appears to execute one general-purpose learning algorithm capable of processing whatever sensory stream is fed into it. Artificial Neural Networks are designed as computational models inspired by this unified architecture.

7. The Mathematical Neuron: Perceptron & Activation Functions

A biological neuron (Slide 24) consists of a cell body (soma), nucleus, receiving tree-like dendrites, an axon hillock where electrical impulses accumulate, an axon transmitting the signal, and synaptic terminals interfacing with downstream cells.

The mathematical model of an artificial neuron (Slides 25–26, 36–37) abstracts this process:

Definition 7.1 (Mathematical Single Neuron) A single neuron receives an input vector \(x \in \mathbb{R}^d\), computes a weighted affine combination (pre-activation \(z\)), and applies a non-linear activation function \(g(z)\): \[ z = w^T x + b = \sum_{j=1}^d w_j x_j + b = \theta^T X \quad (\text{with } x_0 = 1, \theta_0 = b) \] \[ a = g(z) = g\left(w^T x + b\right) \] where \(w\) represents synaptic weights, \(b\) is the threshold bias, and \(a\) is the activation output.

Comparison of Fundamental Single-Neuron Models

  • The Perceptron (Slide 37): Threshold activation function: \[ \hat{y} = \begin{cases} 1 & \text{if } w^T x + b \ge 0 \\ 0 & \text{if } w^T x + b < 0 \end{cases} \]
  • The Logistic Unit (Slide 26, 36): Sigmoid activation: \[ h_\theta(x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}} \] A single neuron with a sigmoid activation is mathematically equivalent to Logistic Regression.
  • Regression Unit with ReLU (Slide 25): \[ h_\theta(x) = \max(0, w^T x + b) \] Used for non-negative continuous regression (e.g. house price prediction).

Catalog of Non-Linear Activation Functions (Slides 32, 40, 41)

Function Formula Derivative \(g'(z)\) Output Range Key Characteristics & Applications
Sigmoid \(\sigma(z) = \frac{1}{1 + e^{-z}}\) \(\sigma(z)(1 - \sigma(z))\) \((0, 1)\) Historical default; saturates at extremes causing vanishing gradients.
Tanh \(\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}\) \(1 - \tanh^2(z)\) \((-1, 1)\) Zero-centered activations; still suffers from vanishing gradients.
ReLU \(\max(0, z) = z \mathbf{1}_{z > 0}\) \(\mathbf{1}_{z > 0}\) \([0, \infty)\) Non-saturating for \(z > 0\), highly efficient gradient flow; risk of "dying ReLU".
Leaky ReLU \(\max(z, \gamma z), \gamma \in (0, 1)\) \(\begin{cases} 1 & z > 0 \\ \gamma & z \le 0 \end{cases}\) \((-\infty, \infty)\) Prevents dead neurons by ensuring a small non-zero slope for negative inputs.
GELU \(\frac{z}{2}\left[1 + \text{erf}\left(\frac{z}{\sqrt{2}}\right)\right]\) Smooth curve \([-0.17, \infty)\) Foundational in modern Transformers, BERT, GPT, and language models.
Softplus \(\frac{1}{\beta}\ln(1 + e^{\beta z}), \beta > 0\) \(\frac{1}{1 + e^{-\beta z}}\) \((0, \infty)\) Smooth, infinitely differentiable continuous approximation to ReLU.

8. Stacking Neurons, Multi-Layer Perceptrons & Non-Linearity Collapse

Intuitive House Price Prediction Example (Slides 27–28)

Consider predicting house price \(y\) from four features: Size (\(x_1\)), # Bedrooms (\(x_2\)), Zip Code (\(x_3\)), and Wealth index (\(x_4\)).

A human domain expert might manually engineer intermediate concepts:

  • \(a_1 = \text{ReLU}(\theta_1 x_1 + \theta_2 x_2 + \theta_3)\) captures Family Size capacity.
  • \(a_2 = \text{ReLU}(\theta_4 x_3 + \theta_5)\) captures neighborhood Walkability.
  • \(a_3 = \text{ReLU}(\theta_6 x_3 + \theta_7 x_4 + \theta_8)\) captures School Quality.
  • Output: \(\bar{h}_\theta(x) = \theta_9 a_1 + \theta_{10} a_2 + \theta_{11} a_3 + \theta_{12} = \text{Price } y\).

The Neural Network Breakthrough: Instead of handcrafting which features connect to which intermediate neurons, we construct a Fully Connected (Dense) layer where every input feature is connected to every hidden neuron. The network discovers its own optimal intermediate latent concepts automatically through gradient optimization!

Vectorization & GPU Parallelism (Slide 30)

Slide 30 highlights the fundamental hardware bridge: "Vectorization and matrix formulation are essential for parallel acceleration on modern GPUs and SIMD hardware."

Deep neural network evaluation is structured as alternating Matrix Multiplications (\(MM\)) and element-wise non-linear activations (\(g\)):

\[ MM \longrightarrow g \longrightarrow MM \longrightarrow g \dots \longrightarrow g \longrightarrow h_\theta(x) \]

Mathematically, deep networks are functional compositions:

\[ h_\theta(x) = f_L \circ f_{L-1} \circ \dots \circ f_1(x) \]
Theorem 8.1 (Why Don't We Use the Identity Function? Non-Linearity Collapse) Suppose all hidden activation functions were linear/identity: \(g(z) = z\) (Slide 34). Then for a two-layer network: \[ a^{[1]} = W^{[1]} x + b^{[1]} \] \[ h_\theta(x) = W^{[2]} a^{[1]} + b^{[2]} = W^{[2]} \left(W^{[1]} x + b^{[1]}\right) + b^{[2]} = \left(W^{[2]} W^{[1]}\right) x + \left(W^{[2]} b^{[1]} + b^{[2]}\right) \] Defining the composite weight matrix \(\tilde{W} = W^{[2]} W^{[1]}\) and composite bias \(\tilde{b} = W^{[2]} b^{[1]} + b^{[2]}\): \[ h_\theta(x) = \tilde{W} x + \tilde{b} \]
The Linearity Collapse Principle:
Because the composition of linear maps is itself strictly linear, any multi-layer neural network with linear activation functions—regardless of whether it has 2 layers or 10,000 layers—collapses identically to a single linear regression model! Non-linear activations are strictly necessary to produce expressive non-linear hypotheses and universal function approximation.

9. Learned Feature Maps & Layer Dimension Theorems

Deep Networks vs. Kernel Methods (Slides 31, 35)

Slide 35 illuminates a profound conceptual link between deep learning and the Kernel Trick:

\[ h_\theta(x) = W^{[r]} \phi_\beta(x) + b^{[r]} \]
Comparison: Kernel Methods vs. Deep Neural Networks
  • Kernel Methods (SVM, Ridge Regression): The non-linear feature map \(\phi(x)\) is chosen a priori (e.g. polynomial, Gaussian RBF) and remains fixed throughout learning.
  • Deep Neural Networks: The activations of the penultimate layer \(a^{[r-1]} = \phi_\beta(x)\) act as a feature map. However, this feature map is parameterized by all previous layer weights \(\beta\) and learned directly from data:
    (\(\phi(x) = a^{[L-1]}\) represents the internal feature representation learned autonomously by hidden layers).
Deep neural networks are end-to-end representation learning machines.

Formal Mathematical Indexing & Forward Propagation (Slides 38–42)

To avoid index ambiguity, we adopt standard Stanford/MIT matrix indexing conventions:

  • \(l \in \{1, 2, \dots, L\}\): Layer index (\(l=1\) is input layer, \(l=L\) is output layer).
  • \(a_i^{(l)}\): The activation of neuron \(i\) in layer \(l\).
  • \(x_0 = 1, a_0^{(l)} = 1\): Bias units.
  • \(\Theta_{ij}^{(l)}\): Weight controlling the link from unit \(j\) in layer \(l\) to unit \(i\) in layer \(l+1\) (Row index \(i\) corresponds to destination unit in layer \(l+1\); column index \(j\) corresponds to source unit in layer \(l\)).
Worked Concrete Example: 3-Layer Network (Slides 39, 42) Consider a network with 3 inputs (\(x_1, x_2, x_3\) plus bias \(x_0=1\)), a hidden layer with 3 neurons (\(a_1^{(2)}, a_2^{(2)}, a_3^{(2)}\) plus bias \(a_0^{(2)}=1\)), and a single output neuron \(a_1^{(3)}\):

Hidden Layer Activations:

\[ z_1^{(2)} = \Theta_{10}^{(1)} x_0 + \Theta_{11}^{(1)} x_1 + \Theta_{12}^{(1)} x_2 + \Theta_{13}^{(1)} x_3 \implies a_1^{(2)} = g(z_1^{(2)}) \] \[ z_2^{(2)} = \Theta_{20}^{(1)} x_0 + \Theta_{21}^{(1)} x_1 + \Theta_{22}^{(1)} x_2 + \Theta_{23}^{(1)} x_3 \implies a_2^{(2)} = g(z_2^{(2)}) \] \[ z_3^{(2)} = \Theta_{30}^{(1)} x_0 + \Theta_{31}^{(1)} x_1 + \Theta_{32}^{(1)} x_2 + \Theta_{33}^{(1)} x_3 \implies a_3^{(2)} = g(z_3^{(2)}) \]

Output Layer Activation:

\[ z_1^{(3)} = \Theta_{10}^{(2)} a_0^{(2)} + \Theta_{11}^{(2)} a_1^{(2)} + \Theta_{12}^{(2)} a_2^{(2)} + \Theta_{13}^{(2)} a_3^{(2)} \implies h_\Theta(x) = a_1^{(3)} = g(z_1^{(3)}) \]
Theorem 9.1 (The Weight Matrix Dimension Theorem - Slide 42) If layer \(l\) contains \(s_l\) functional units and layer \(l+1\) contains \(s_{l+1}\) functional units, then the weight matrix \(\Theta^{(l)}\) connecting layer \(l\) to layer \(l+1\) has dimensions: \[ \dim\left(\Theta^{(l)}\right) = s_{l+1} \times (s_l + 1) \]

(Matrix Dimension Summary:
• Columns: Number of units in layer \(l\) plus one bias unit \(\implies s_l + 1\).
• Rows: Number of units in destination layer \(l+1 \implies s_{l+1}\)).

This elegant matrix formulation sets the stage for Lecture 21, where we will derive the generalized Backpropagation algorithm using the multivariate chain rule across arbitrary computational graphs.
