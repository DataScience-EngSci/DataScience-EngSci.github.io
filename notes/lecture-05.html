1. The Statistical Setup: Samples, Parameters, and Estimators

In statistical inference, we observe data generated by an underlying probabilistic mechanism characterized by unknown parameters. Our goal is to formulate mathematical rules (statistics) that output accurate guesses for these unknown constants.

Definition 1.1 (Random Sample, Estimators & Estimates)
  • Random Sample: A set of \(n\) random variables: \[ X_1, X_2, \dots, X_n \overset{\text{i.i.d.}}{\sim} f(x; \theta), \quad \theta \in \Theta \] representing measurements before they are sampled, observed, and “locked in” (e.g., \(X_1, \dots, X_n \sim \Gamma(\alpha, \beta)\)).
  • Parameter (\(\theta\)): A generic numerical constant governing the population distribution, such as \(\theta = \mu\), \(\theta = p\), \(\theta = \lambda\), or a parameter vector \(\boldsymbol{\theta} = (\alpha, \beta)\).
  • Estimator (\(\hat{\theta}\)): A random variable that is a mathematical function of the sample data: \[ \hat{\theta} = W(X_1, X_2, \dots, X_n) \] Example: The sample mean \(\hat{\theta} = \bar{X} = \frac{1}{n}\sum_{i=1}^n X_i\) (written in uppercase).
  • Estimate (\(\hat{\theta}_{\text{obs}}\)): A fixed numerical realization computed once the data is observed and locked in: \[ \hat{\theta}_{\text{obs}} = W(x_1, \dots, x_n) \] Example: \(\hat{\theta}_{\text{obs}} = \bar{x} = 42.8\).

2. Unbiasedness & The Bias of Naive Sample Variance

Definition 2.1 (Bias and Unbiasedness) The bias of an estimator \(\hat{\theta}\) of parameter \(\theta\) is defined as: \[ \text{Bias}(\hat{\theta}) = E[\hat{\theta}] - \theta \] An estimator is said to be unbiased if \(\text{Bias}(\hat{\theta}) = 0\), meaning: \[ E[\hat{\theta}] = \theta \quad \forall \theta \in \Theta \]

For any distribution with finite population mean \(\mu = E[X_i]\), the sample mean \(\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i\) is always unbiased:

\[ E[\bar{X}] = E\left[\frac{1}{n}\sum_{i=1}^n X_i\right] = \frac{1}{n}\sum_{i=1}^n E[X_i] = \frac{1}{n}(n\mu) = \mu \]

However, the naive "plug-in" estimator for the population variance \(\sigma^2 = \text{Var}(X_i)\), defined as:

\[ S_1^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2 \] is systematically biased downward!

3. Rigorous Proof: Bessel's Correction

Theorem 3.1 (Expected Value of Sample Variance) Let \(X_1, \dots, X_n\) be i.i.d. with mean \(\mu\) and variance \(\sigma^2\). Then: \[ E\left[S_1^2\right] = E\left[\frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2\right] = \frac{n - 1}{n}\sigma^2 \] Consequently, the corrected sample variance: \[ S^2 = \frac{1}{n - 1}\sum_{i=1}^n (X_i - \bar{X})^2 \] is strictly unbiased: \(E[S^2] = \sigma^2\).
Proof Observe that for each term, we can add and subtract the population mean \(\mu\): \[ (X_i - \bar{X}) = (X_i - \mu) - (\bar{X} - \mu) \] Squaring both sides: \[ (X_i - \bar{X})^2 = (X_i - \mu)^2 - 2(X_i - \mu)(\bar{X} - \mu) + (\bar{X} - \mu)^2 \] Summing over all \(i = 1, \dots, n\): \[ \sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n (X_i - \mu)^2 - 2(\bar{X} - \mu)\underbrace{\sum_{i=1}^n (X_i - \mu)}_{n(\bar{X} - \mu)} + n(\bar{X} - \mu)^2 \] \[ \sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n (X_i - \mu)^2 - n(\bar{X} - \mu)^2 \] Now take the mathematical expectation of both sides: \[ E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sum_{i=1}^n E\left[(X_i - \mu)^2\right] - n E\left[(\bar{X} - \mu)^2\right] \] Recall that \(E[(X_i - \mu)^2] = \text{Var}(X_i) = \sigma^2\), and \(E[(\bar{X} - \mu)^2] = \text{Var}(\bar{X}) = \frac{\sigma^2}{n}\). Substituting these: \[ E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = n\sigma^2 - n\left(\frac{\sigma^2}{n}\right) = n\sigma^2 - \sigma^2 = (n - 1)\sigma^2 \] Dividing by \(n\): \[ E[S_1^2] = \frac{n - 1}{n}\sigma^2 \quad \implies \quad E[S^2] = E\left[\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sigma^2 \quad \blacksquare \]

4. The Maximum Likelihood Principle & Score Function

Motivating Intuition: Flipping a Biased Coin (Slide 5.2)

Suppose we flip a coin whose true probability \(p\) of landing “Heads” is known to belong to a discrete candidate set: \(p \in \{0.2, 0.3, 0.8\}\).

  • 20-Flip Experiment: We flip the coin \(20\) times and observe \(17\) Heads and \(3\) Tails. Which parameter value \(\{0.2, 0.3, 0.8\}\) seems “most likely”? Intuitively, \(0.8\) makes the observed outcome far more probable than \(0.2\) or \(0.3\).
  • 2-Flip Experiment: Now consider flipping only twice: \(X_1, X_2 \overset{\text{i.i.d.}}{\sim} \text{Bernoulli}(p)\). The joint probability mass function evaluated across all possible realizations \((x_1, x_2)\) is: \[ P(X_1 = x_1, X_2 = x_2; p) = p^{x_1 + x_2} (1 - p)^{2 - (x_1 + x_2)} \]
    Candidate \(p\) \((0, 0)\) [T, T] \((0, 1)\) [T, H] \((1, 0)\) [H, T] \((1, 1)\) [H, H] MLE Decision \(\hat{p}\)
    \(p = 0.2\) 0.64 0.16 0.16 0.04 Best for \((0, 0)\)
    \(p = 0.3\) 0.49 0.21 0.21 0.09 Best for \((0, 1)\) or \((1, 0)\)
    \(p = 0.8\) 0.04 0.16 0.16 0.64 Best for \((1, 1)\)

    If we observe \((0, 0)\), \(p = 0.2\) yields highest probability (\(0.64\)). If we observe \((0, 1)\) or \((1, 0)\), \(p = 0.3\) maximizes probability (\(0.21\)). If we observe \((1, 1)\), \(p = 0.8\) maximizes probability (\(0.64\)). This is the heart of Maximum Likelihood: select the parameter candidate that maximizes the likelihood of having generated our observed data.

Definition 4.1 (Likelihood & Log-Likelihood Functions) For i.i.d. observations \(\mathbf{x}\), the Likelihood Function \(L(\theta; \mathbf{x})\) is the joint density viewed as a function of \(\theta\): \[ L(\theta; \mathbf{x}) = \prod_{i=1}^n f(x_i; \theta) \] Because the product of small probabilities causes numerical underflow, and products are cumbersome to differentiate, we work with the strictly monotonic transformation: the Log-Likelihood Function: \[ \ell(\theta; \mathbf{x}) = \ln L(\theta; \mathbf{x}) = \sum_{i=1}^n \ln f(x_i; \theta) \] The Maximum Likelihood Estimator (MLE) is the argument maximizing the log-likelihood: \[ \hat{\theta}_{\text{MLE}} = \arg\max_{\theta \in \Theta} \ell(\theta; \mathbf{x}) \]
Definition 4.2 (Score Function & First-Order Condition) The derivative of the log-likelihood with respect to \(\theta\) is known as the Score Function: \[ S(\theta) = \frac{\partial}{\partial\theta} \ell(\theta; \mathbf{x}) \] A candidate interior maximum must satisfy the First-Order Condition (FOC): \[ S(\hat{\theta}) = 0 \] and the Second-Order Condition (SOC) for local concavity: \[ \left.\frac{\partial^2}{\partial\theta^2}\ell(\theta; \mathbf{x})\right|_{\theta = \hat{\theta}} < 0 \]

5. Step-by-Step Derivation: Bernoulli Parameter \(p\)

Let \(X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \text{Bernoulli}(p)\), where \(p \in (0, 1)\) and \(X_i \in \{0, 1\}\).

Derivation: Bernoulli MLE Step 1: Write the PMF and Likelihood: \[ f(x_i; p) = p^{x_i}(1 - p)^{1 - x_i} \] \[ L(p) = \prod_{i=1}^n p^{x_i}(1 - p)^{1 - x_i} = p^{\sum_{i=1}^n x_i} (1 - p)^{n - \sum_{i=1}^n x_i} \] Step 2: Compute Log-Likelihood: \[ \ell(p) = \left(\sum_{i=1}^n x_i\right) \ln p + \left(n - \sum_{i=1}^n x_i\right) \ln(1 - p) \] Step 3: Differentiate and Solve FOC: \[ \frac{d\ell}{dp} = \frac{\sum_{i=1}^n x_i}{p} - \frac{n - \sum_{i=1}^n x_i}{1 - p} = 0 \] \[ (1 - p)\sum_{i=1}^n x_i = p\left(n - \sum_{i=1}^n x_i\right) \implies \sum_{i=1}^n x_i - p\sum_{i=1}^n x_i = n p - p\sum_{i=1}^n x_i \] \[ n p = \sum_{i=1}^n x_i \implies \hat{p}_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n X_i = \bar{X} \] Step 4: Check Second-Order Condition: \[ \frac{d^2\ell}{dp^2} = -\frac{\sum_{i=1}^n x_i}{p^2} - \frac{n - \sum_{i=1}^n x_i}{(1 - p)^2} < 0 \quad \forall p \in (0, 1) \] Since the second derivative is strictly negative everywhere, \(\hat{p}_{\text{MLE}} = \bar{X}\) is the unique global maximum.

6. Step-by-Step Derivation: Exponential Rate \(\lambda\)

Let \(X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \text{Exponential}(\lambda)\), with PDF \(f(x; \lambda) = \lambda e^{-\lambda x}\) for \(x > 0\).

Derivation: Exponential Rate MLE Step 1: Likelihood: \[ L(\lambda) = \prod_{i=1}^n \lambda e^{-\lambda x_i} = \lambda^n \exp\left(-\lambda \sum_{i=1}^n x_i\right) \] Step 2: Log-Likelihood: \[ \ell(\lambda) = n \ln \lambda - \lambda \sum_{i=1}^n x_i \] Step 3: First-Order Condition: \[ \frac{d\ell}{d\lambda} = \frac{n}{\lambda} - \sum_{i=1}^n x_i = 0 \implies \hat{\lambda}_{\text{MLE}} = \frac{n}{\sum_{i=1}^n X_i} = \frac{1}{\bar{X}} \] Step 4: Second-Order Condition: \[ \frac{d^2\ell}{d\lambda^2} = -\frac{n}{\lambda^2} < 0 \quad \forall \lambda > 0 \] Because \(E[X_i] = \frac{1}{\lambda}\), the sample average is intuitively inverted to estimate the rate parameter \(\lambda\).
Summary Takeaway The Maximum Likelihood principle provides an automated, objective methodology for deriving estimators. In Lecture 06, we extend MLE to continuous multiparameter distributions (Normal distribution) and non-differentiable boundary cases (Uniform distribution), along with the celebrated Invariance Property.
