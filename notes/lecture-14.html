1. Supervised Learning Taxonomy: Continuous vs. Discrete Problems

Supervised learning operates on labeled training examples of the form \(\mathcal{D} = \{(x^{(i)}, y^{(i)})\}_{i=1}^m\), where \(x^{(i)} \in \mathcal{X}\) represents the input feature vector of example \(i\), and \(y^{(i)} \in \mathcal{Y}\) denotes its corresponding true target label. The supervised learning universe partitions fundamentally according to the topological nature of the output space \(\mathcal{Y}\):

Definition 1.1 (Regression vs. Classification)
  • Regression: The target space is continuous, typically \(\mathcal{Y} = \mathbb{R}\) (or \(\mathbb{R}^k\)). The algorithm fits a continuous response surface to predict numerical quantities. Examples include real estate market valuation, financial asset pricing, temperature forecasting, and load prediction.
  • Classification: The target space is categorical, consisting of a discrete set of unordered class labels \(\mathcal{Y} \in \{0, 1\}\) (binary classification) or \(\mathcal{Y} \in \{1, 2, \dots, K\}\) (multiclass). The model constructs geometric decision boundaries partitioning feature space into decision regions. Slide 2 illustrates this via the petal length vs. petal width decision boundary separating Iris-versicolor from Iris-virginica.

Within regression, models range in structural complexity:

  • Simple Linear Regression: Modeling the relationship between a single predictor \(x\) and response \(y\) via a line.
  • Multivariate Linear Regression: Modeling \(y\) as a linear combination of multiple input variables \(x_1, x_2, \dots, x_n\).
  • Polynomial Regression: Fitting curved non-linear trajectories by augmenting feature space with powers \(x^2, x^3, \dots\) while preserving linear parameterization.

The supervised learning pipeline proceeds systematically:

Training Set \(\{(x^{(i)}, y^{(i)})\}\) ⟶ Learning Algorithm ⟶ Hypothesis \(h_\theta(x)\) ⟶ Predicted Price \(\hat{y}\)

In univariate linear regression, the hypothesis takes the affine form: \[ h_\theta(x) = \theta_0 + \theta_1 x \] where \(\theta_0\) represents the intercept and \(\theta_1\) represents the slope.

3. The Mean Squared Error (MSE) Cost Function

To determine the optimal parameters \(\theta = (\theta_0, \theta_1)^T\), we require an objective criterion measuring how well the line fits the empirical observations. The error for the \(i\)-th training instance is the vertical discrepancy between predicted and true value: \(e^{(i)} = h_\theta(x^{(i)}) - y^{(i)}\).

Definition 3.1 (Mean Squared Error Cost Function) The standard objective function is the Mean Squared Error (MSE), denoted \(J(\theta_0, \theta_1)\): \[ J(\theta_0, \theta_1) = \frac{1}{2m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right)^2 \] where \(m\) is the total number of training examples. The scaling constant \(\frac{1}{2m}\) is chosen intentionally: dividing by \(m\) ensures the cost represents an average error independent of sample size, while the denominator constant \(2\) cancels cleanly with the exponent \(2\) when computing derivatives.
Worked Pedagogical Example (Slide 10: Simplified 1D Case with \(\theta_0 = 0\)) To develop geometric intuition, suppress the intercept by fixing \(\theta_0 = 0\). The hypothesis reduces to a line through the origin: \(h_\theta(x) = \theta_1 x\), and the cost becomes a single-variable function \(J(\theta_1)\).

Consider a toy training dataset of \(m=3\) points: \[ (x^{(1)}, y^{(1)}) = (1, 1), \quad (x^{(2)}, y^{(2)}) = (2, 2), \quad (x^{(3)}, y^{(3)}) = (3, 3) \] Let us evaluate \(J(\theta_1)\) across three candidate slope values:
  1. Candidate \(\theta_1 = 1\): Predictions match targets perfectly: \(h(1)=1, h(2)=2, h(3)=3\). \[ J(1) = \frac{1}{2(3)} \left[(1-1)^2 + (2-2)^2 + (3-3)^2\right] = 0 \]
  2. Candidate \(\theta_1 = 0.5\): Predictions are \(h(1)=0.5, h(2)=1.0, h(3)=1.5\). \[ J(0.5) = \frac{1}{6} \left[(0.5-1)^2 + (1-2)^2 + (1.5-3)^2\right] = \frac{1}{6} [0.25 + 1.0 + 2.25] = \frac{3.5}{6} \approx 0.583 \]
  3. Candidate \(\theta_1 = 2\): Predictions are \(h(1)=2, h(2)=4, h(3)=6\). \[ J(2) = \frac{1}{6} \left[(2-1)^2 + (4-2)^2 + (6-3)^2\right] = \frac{1}{6} [1 + 4 + 9] = \frac{14}{6} \approx 2.333 \]
Plotting \(J(\theta_1)\) against \(\theta_1\) yields a strictly convex quadratic parabola centered precisely at its global minimum \(\theta_1^* = 1\).

4. The Gradient Descent Optimization Algorithm

When optimizing both parameters \(\theta_0\) and \(\theta_1\), the parameter space is \(\mathbb{R}^2\), and \(J(\theta_0, \theta_1)\) forms a 3D bowl-shaped surface whose level curves form concentric ellipses (Slide 17). Rather than guessing blindly, we utilize Gradient Descent.

Definition 4.1 (Gradient Descent General Update Rule) Starting from an initial parameter guess \(\theta^{(0)}\), gradient descent iteratively steps in the direction of steepest local descent—the negative gradient: \[ \theta_j := \theta_j - \alpha \frac{\partial}{\partial \theta_j} J(\theta_0, \theta_1) \quad (\text{for } j = 0, 1) \] where \(\alpha > 0\) is the learning rate, governing the step length taken along the negative gradient vector.
Critical Implementation Rule: Simultaneous Updates (Slide 13) All parameters must be updated simultaneously at each iteration step:
✓ Correct (Simultaneous Update): \[ \begin{aligned} \text{temp0} &:= \theta_0 - \alpha \frac{\partial}{\partial \theta_0} J(\theta_0, \theta_1) \\ \text{temp1} &:= \theta_1 - \alpha \frac{\partial}{\partial \theta_1} J(\theta_0, \theta_1) \\ \theta_0 &:= \text{temp0} \\ \theta_1 &:= \text{temp1} \end{aligned} \]
✗ Incorrect (Sequential Update): \[ \begin{aligned} \text{temp0} &:= \theta_0 - \alpha \frac{\partial}{\partial \theta_0} J(\theta_0, \theta_1) \\ \theta_0 &:= \text{temp0} \\ \text{temp1} &:= \theta_1 - \alpha \frac{\partial}{\partial \theta_1} J(\mathbf{\theta_0}, \theta_1) \\ \theta_1 &:= \text{temp1} \end{aligned} \] Error: Calculating \(\text{temp1}\) using the newly modified \(\theta_0\) distorts the true gradient vector!

5. Step-by-Step Gradient Derivation & Simultaneous Updates

Slide 16 provides the explicit handwritten derivation of the partial derivatives for the univariate linear regression model:

Mathematical Derivation (Slide 16) Substitute the hypothesis \(h_\theta(x^{(i)}) = \theta_0 + \theta_1 x^{(i)}\) directly into the cost function: \[ J(\theta_0, \theta_1) = \frac{1}{2m} \sum_{i=1}^m \left(\theta_0 + \theta_1 x^{(i)} - y^{(i)}\right)^2 \] Applying the chain rule of differentiation:
  1. Partial Derivative with respect to intercept \(\theta_0\) (\(j=0\)): \[ \begin{aligned} \frac{\partial}{\partial \theta_0} J(\theta_0, \theta_1) &= \frac{\partial}{\partial \theta_0} \left[ \frac{1}{2m} \sum_{i=1}^m \left(\theta_0 + \theta_1 x^{(i)} - y^{(i)}\right)^2 \right] \\ &= \frac{1}{2m} \sum_{i=1}^m 2 \left(\theta_0 + \theta_1 x^{(i)} - y^{(i)}\right) \cdot \frac{\partial}{\partial \theta_0} \left(\theta_0 + \theta_1 x^{(i)} - y^{(i)}\right) \\ &= \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) \cdot (1) \\ &= \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) \end{aligned} \]
  2. Partial Derivative with respect to slope \(\theta_1\) (\(j=1\)): \[ \begin{aligned} \frac{\partial}{\partial \theta_1} J(\theta_0, \theta_1) &= \frac{\partial}{\partial \theta_1} \left[ \frac{1}{2m} \sum_{i=1}^m \left(\theta_0 + \theta_1 x^{(i)} - y^{(i)}\right)^2 \right] \\ &= \frac{1}{2m} \sum_{i=1}^m 2 \left(\theta_0 + \theta_1 x^{(i)} - y^{(i)}\right) \cdot \frac{\partial}{\partial \theta_1} \left(\theta_0 + \theta_1 x^{(i)} - y^{(i)}\right) \\ &= \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) \cdot x^{(i)} \end{aligned} \]

Plugging these gradients into the update equations yields the concrete algorithm:

Batch Gradient Descent for Univariate Linear Regression Repeat until numerical convergence: \[ \begin{aligned} \theta_0 &:= \theta_0 - \frac{\alpha}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) \\ \theta_1 &:= \theta_1 - \frac{\alpha}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x^{(i)} \end{aligned} \]

6. Learning Rate Dynamics & Convex vs. Non-Convex Surfaces

A. Mechanics of the Step Size (Slide 15)

The handwritten annotations in Slide 15 demonstrate why the negative gradient guarantees movement toward the minimum:

  • Right of Minimum: Here the tangent slope is positive (\(\frac{d}{d\theta_1} J(\theta_1) > 0\)). The update rule subtracts a positive number: \[ \theta_1 := \theta_1 - \alpha \cdot (\text{positive}) \implies \theta_1 \text{ decreases (moves left toward minimum)}. \]
  • Left of Minimum: Here the tangent slope is negative (\(\frac{d}{d\theta_1} J(\theta_1) < 0\)). The update rule subtracts a negative number: \[ \theta_1 := \theta_1 - \alpha \cdot (\text{negative}) = \theta_1 + \alpha \cdot |\text{derivative}| \implies \theta_1 \text{ increases (moves right toward minimum)}. \]

B. Convex vs. Non-Convex Topologies (Slides 19–21)

Convexity of Ordinary Least Squares A defining property of the linear regression MSE cost function is that it is strictly convex (a single "bowl" shape with positive semi-definite Hessian). It has no local minima—only a single unique global minimum. Any local minimum is guaranteed to be the global minimum.

In contrast, complex models like Deep Neural Networks produce non-convex surfaces (Slides 20–21) riddled with multiple local minima, saddle points, and plateaus. On non-convex surfaces, the final converged parameters depend heavily on the random initialization point \(\theta^{(0)}\).

C. Sensitivity to the Learning Rate \(\alpha\) (Slide 18)

Slide 18 compares two learning rates on a two-dimensional quadratic valley with minimum at \((1, 1)\):

  • (a) Learning Rate \(\alpha = 0.1\): The step size is conservative. The parameters advance smoothly down the valley walls and steadily migrate along the valley floor to the global optimum \((1, 1)\).
  • (b) Learning Rate \(\alpha = 0.6\): The step size is excessively large. It overshoots the valley floor, oscillating violently back and forth across the steep ridge walls, completely failing to converge to the optimum even on this purely convex problem!

Vector & Matrix Notation To express the hypothesis concisely, we define a dummy zeroth feature \(x_0 \equiv 1\). Then: \[ x = \begin{bmatrix} x_0 \\ x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix} \in \mathbb{R}^{n+1} \quad (x_0 = 1), \qquad \theta = \begin{bmatrix} \theta_0 \\ \theta_1 \\ \theta_2 \\ \vdots \\ \theta_n \end{bmatrix} \in \mathbb{R}^{n+1} \] The hypothesis becomes an inner product: \[ h_\theta(x) = \theta^T x = \theta_0 x_0 + \theta_1 x_1 + \dots + \theta_n x_n \]
Multivariate Gradient Descent Algorithm (Slide 34–35) The cost function remains: \[ J(\theta) = \frac{1}{2m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right)^2 \] For \(n \ge 1\), simultaneously update every parameter \(j \in \{0, 1, \dots, n\}\): \[ \theta_j := \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j} = \theta_j - \frac{\alpha}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} \] In compact vector notation: \[ \theta := \theta - \alpha \nabla_\theta J(\theta) \]

8. Practical Optimization: Feature Scaling & Mean Normalization

In multi-feature problems, features frequently operate on drastically different numerical scales. Slides 36–38 explain why this impairs gradient descent and provide explicit normalization methods:

The Geometry of Unscaled Features Suppose \(x_1 = \text{size} \in [0, 2000]\,\text{ft}^2\) and \(x_2 = \text{bedrooms} \in [1, 5]\).
  • Because \(x_1\) is thousands of times larger than \(x_2\), a tiny modification in \(\theta_1\) changes the hypothesis dramatically, whereas \(\theta_2\) must change substantially to make any perceptible difference.
  • The contours of \(J(\theta)\) form extremely elongated, "skinny" elliptical canyons (Slide 36).
  • The gradient points perpendicular to contour lines—which does not point toward the center! Consequently, gradient descent oscillates wildly back and forth across the steep narrow walls, taking hundreds or thousands of redundant zigzag steps.
  • When features are scaled to comparable magnitudes (e.g., \(0 \le x_1, x_2 \le 1\)), the contours become nearly spherical circles. The negative gradient points directly toward the global minimum, achieving convergence in minimal iterations!
Standard Normalization Formulas (Slide 37–38)
  1. Min-Max Scaling: \[ x'_j = \frac{x_j - \min(x_j)}{\max(x_j) - \min(x_j)} \implies 0 \le x'_j \le 1 \]
  2. Mean Normalization: Replace \(x_j\) with: \[ x'_j = \frac{x_j - \mu_j}{s_j} \] where \(\mu_j\) is the sample mean of feature \(j\) in the training set: \(\mu_j = \frac{1}{m} \sum_{i=1}^m x_j^{(i)}\), and \(s_j\) is either the range \((\max(x_j) - \min(x_j))\) or the sample standard deviation \(\sigma_j\).

Concrete Slide Example: If house sizes range from \(0\) to \(2000\) with average \(\mu_1 = 1000\), and bedrooms range from \(1\) to \(5\) with average \(\mu_2 = 2\): \[ x_1 \leftarrow \frac{\text{size} - 1000}{2000} \implies -0.5 \le x_1 \le 0.5, \qquad x_2 \leftarrow \frac{\#\text{bedrooms} - 2}{5} \implies -0.5 \le x_2 \le 0.5 \] Rule: Do NOT normalize the bias feature \(x_0 \equiv 1\).

9. Debugging Gradient Descent & Hyperparameter Selection

A. Monitoring Convergence via Learning Curves (Slides 40–42)

The gold standard diagnostic is plotting \(J(\theta)\) as a function of the number of iterations:

  • Healthy Convergence: \(J(\theta)\) should decrease monotonically after every iteration. As the trajectory approaches the minimum, the gradient \(\|\nabla J\|\) shrinks, and the curve asymptotically flattens out.
  • Automatic Convergence Criterion (Slide 40–41): Declare convergence if \(J(\theta)\) decreases by less than a tolerance threshold \(\epsilon\) (e.g., \(\epsilon = 10^{-3}\)) in a single iteration. However, in practice, visually inspecting the plot is safer than picking an arbitrary \(\epsilon\).
  • Divergence & Oscillation (Slide 42): If the curve ascends over time or oscillates erratically, it indicates that \(\alpha\) is too large! Mathematics proves that for a sufficiently small \(\alpha\), \(J(\theta)\) must strictly decrease on every single iteration.

B. Practical Recipe for Choosing \(\alpha\) (Slide 43)

To find an effective learning rate, test values spaced geometrically by a factor of roughly \(3\): \[ \dots, 0.001, \; 0.003, \; 0.01, \; 0.03, \; 0.1, \; 0.3, \; 1, \; \dots \]

10. Closed-Form Analytical Solution: The Normal Equation

While gradient descent is an iterative algorithm, linear regression admits an exact, closed-form algebraic solution: The Normal Equation.

1D Motivation (Slide 44) For a scalar quadratic function \(J(\theta) = a\theta^2 + b\theta + c\), setting the first derivative to zero yields: \[ \frac{dJ}{d\theta} = 2a\theta + b = 0 \implies \theta = -\frac{b}{2a} \] In multi-dimensional space \(\theta \in \mathbb{R}^{n+1}\), the minimum requires setting all partial derivatives simultaneously to zero: \[ \frac{\partial}{\partial \theta_j} J(\theta) = 0 \quad \text{for all } j = 0, 1, \dots, n \implies \nabla_\theta J(\theta) = \mathbf{0} \]
Matrix Formulation of Ordinary Least Squares (Slide 45) Construct the \(m \times (n+1)\) Design Matrix \(X\) and the \(m \times 1\) target vector \(y\): \[ X = \begin{bmatrix} (x^{(1)})^T \\ (x^{(2)})^T \\ \vdots \\ (x^{(m)})^T \end{bmatrix} = \begin{bmatrix} 1 & x_1^{(1)} & x_2^{(1)} & \dots & x_n^{(1)} \\ 1 & x_1^{(2)} & x_2^{(2)} & \dots & x_n^{(2)} \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 1 & x_1^{(m)} & x_2^{(m)} & \dots & x_n^{(m)} \end{bmatrix}, \qquad y = \begin{bmatrix} y^{(1)} \\ y^{(2)} \\ \vdots \\ y^{(m)} \end{bmatrix} \] For the Portland dataset with \(n=4\) features (Slide 45): \[ X = \begin{bmatrix} 1 & 2104 & 5 & 1 & 45 \\ 1 & 1416 & 3 & 2 & 40 \\ 1 & 1534 & 3 & 2 & 30 \\ 1 & 852 & 2 & 1 & 36 \end{bmatrix}, \qquad y = \begin{bmatrix} 460 \\ 232 \\ 315 \\ 178 \end{bmatrix} \]
Matrix Derivation of the Normal Equation Express the total residual sum of squares in matrix notation: \[ J(\theta) = \frac{1}{2m} (X\theta - y)^T (X\theta - y) = \frac{1}{2m} \left( \theta^T X^T X \theta - 2 y^T X \theta + y^T y \right) \] Taking the matrix gradient with respect to parameter vector \(\theta\): \[ \nabla_\theta J(\theta) = \frac{1}{m} \left( X^T X \theta - X^T y \right) \] Setting the gradient to zero: \[ \frac{1}{m} \left( X^T X \theta - X^T y \right) = \mathbf{0} \implies X^T X \theta = X^T y \] Multiplying on the left by the matrix inverse \((X^T X)^{-1}\) gives the analytic solution: \[ \theta^* = (X^T X)^{-1} X^T y \]

11. Comparative Trade-offs & Singularity of \(X^T X\)

A. Gradient Descent vs. Normal Equation Trade-offs (Slide 46)

Dimension Gradient Descent Normal Equation
Hyperparameters Must carefully select learning rate \(\alpha\) No learning rate \(\alpha\) needed
Iterations Requires many iterative update steps No iterations; solved in a single step
Feature Scaling Essential (prevents oscillatory slowdown) Not required
Computational Complexity \(\mathcal{O}(k \cdot m \cdot n)\) per \(k\) iterations \(\mathcal{O}(m n^2 + n^3)\) due to matrix inversion
Scalability in \(n\) Scales well even when \(n = 10^6\) Prohibitive for \(n > 10^4\); best for \(n \le 1000\)

B. What If \(X^T X\) is Non-Invertible (Singular / Degenerate)? (Slide 47)

Pathologies Leading to Singularity The \((n+1) \times (n+1)\) matrix \(X^T X\) fails to be invertible (i.e., \(\det(X^T X) = 0\)) under two primary conditions:
  1. Redundant (Linearly Dependent) Features: Two or more features are collinear.
    Example: Including house size in square feet (\(x_1\)) and house size in square meters (\(x_2\)). Since \(1\,\text{m}^2 \approx 10.7639\,\text{ft}^2\), \(x_1 = 10.7639 x_2\), making the columns linearly dependent and \(\text{rank}(X) < n+1\).
    Remedy: Delete redundant, highly correlated features.
  2. Too Many Features (\(m \le n\)): The number of training observations \(m\) is smaller than or equal to the number of feature parameters \(n\) (e.g., \(m = 10\) training samples, but \(n = 100\) features). The system is underdetermined with infinite exact solutions.
    Remedies:
    • Perform feature selection or dimensionality reduction.
    • Apply Regularization (Ridge regression adds \(\lambda I\) to \(X^T X\), strictly ensuring positive definiteness and invertibility—covered in Lecture 17).
    • Use the Moore-Penrose Pseudoinverse (\(\text{pinv}\) in MATLAB/NumPy), which solves for the minimum-norm parameter vector even when \(X^T X\) is singular.
