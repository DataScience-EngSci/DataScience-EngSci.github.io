1. Binary Cross-Entropy Loss & The Sigmoid Derivative Identity

Building upon the conceptual foundations introduced in Lecture 15, we consider the binary classification setting where targets \(y^{(i)} \in \{0, 1\}\) and the hypothesis is parameterized via the logistic sigmoid function: \[ h_\theta(x) = \sigma(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}} \]

A. Cross-Entropy Loss Formulation (Slides 1–2)

The per-instance penalty for predicting \(h_\theta(x) \in (0, 1)\) when the true label is \(y\) is defined piecewise: \[ \text{Cost}\left(h_\theta(x), y\right) = \begin{cases} -\log\left(h_\theta(x)\right) & \text{if } y = 1 \\ -\log\left(1 - h_\theta(x)\right) & \text{if } y = 0 \end{cases} \] Since \(y\) strictly takes values in \(\{0, 1\}\), these two mutually exclusive branches are unified into a single algebraic statement: \[ \text{Cost}\left(h_\theta(x), y\right) = -y \log\left(h_\theta(x)\right) - (1 - y) \log\left(1 - h_\theta(x)\right) \] Averaged across the training dataset of \(m\) observations, we obtain the total Binary Cross-Entropy Loss Function: \[ J(\theta) = -\frac{1}{m} \sum_{i=1}^m \left[ y^{(i)} \log\left(h_\theta(x^{(i)})\right) + \left(1 - y^{(i)}\right) \log\left(1 - h_\theta(x^{(i)})\right) \right] \] where \(h_\theta(x^{(i)}) = P(y=1 \mid x^{(i)}; \theta)\) and \(1 - h_\theta(x^{(i)}) = P(y=0 \mid x^{(i)}; \theta)\).

B. The Derivative of the Sigmoid Function (Slide 4)

Lemma 1.1 (Sigmoid Derivative Identity) Let \(\sigma(z) = \frac{1}{1 + e^{-z}}\). The derivative \(\sigma'(z)\) satisfies: \[ \frac{d}{dz}\sigma(z) = \sigma(z)\left(1 - \sigma(z)\right) \]
Proof: Applying the quotient / power rule of elementary calculus: \[ \begin{aligned} \frac{d}{dz}\left(1 + e^{-z}\right)^{-1} &= -(1 + e^{-z})^{-2} \cdot \frac{d}{dz}\left(1 + e^{-z}\right) \\ &= -(1 + e^{-z})^{-2} \cdot \left(-e^{-z}\right) \\ &= \frac{e^{-z}}{(1 + e^{-z})^2} \\ &= \frac{1}{1 + e^{-z}} \cdot \frac{e^{-z}}{1 + e^{-z}} \\ &= \frac{1}{1 + e^{-z}} \cdot \left(\frac{1 + e^{-z} - 1}{1 + e^{-z}}\right) \\ &= \frac{1}{1 + e^{-z}} \cdot \left(1 - \frac{1}{1 + e^{-z}}\right) \\ &= \sigma(z)\left(1 - \sigma(z)\right) \quad \blacksquare \end{aligned} \]

By applying the multivariate Chain Rule to the hypothesis \(\sigma(\theta^T x)\) where \(z = \theta^T x = \sum_{k=0}^n \theta_k x_k\): \[ \frac{\partial z}{\partial \theta_j} = x_j \] Therefore: \[ \frac{\partial}{\partial \theta_j} \sigma(\theta^T x) = \frac{\partial \sigma(z)}{\partial z} \cdot \frac{\partial z}{\partial \theta_j} = \sigma(\theta^T x)\left(1 - \sigma(\theta^T x)\right) x_j \]

2. Rigorous Derivation of the Logistic Gradient Descent Update

To minimize \(J(\theta)\), we compute its gradient \(\nabla_\theta J(\theta)\) with respect to each parameter \(\theta_j\) (\(j = 0, 1, \dots, n\)).

Theorem 2.1 (The Gradient of Binary Cross-Entropy) For any parameter \(\theta_j\), the partial derivative of \(J(\theta)\) is: \[ \frac{\partial J(\theta)}{\partial \theta_j} = \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} \]
Step-by-Step Analytical Proof:
Consider the loss for a single observation \(i\): \[ \ell_i(\theta) = -y^{(i)} \log\left(h_\theta(x^{(i)})\right) - (1 - y^{(i)}) \log\left(1 - h_\theta(x^{(i)})\right) \] Differentiating \(\ell_i(\theta)\) with respect to \(h_\theta(x^{(i)})\): \[ \frac{\partial \ell_i}{\partial h_\theta(x^{(i)})} = -\frac{y^{(i)}}{h_\theta(x^{(i)})} - \frac{1 - y^{(i)}}{1 - h_\theta(x^{(i)})} \cdot (-1) = -\frac{y^{(i)}}{h_\theta(x^{(i)})} + \frac{1 - y^{(i)}}{1 - h_\theta(x^{(i)})} \] Finding a common algebraic denominator: \[ \frac{\partial \ell_i}{\partial h_\theta(x^{(i)})} = \frac{-y^{(i)}\left(1 - h_\theta(x^{(i)})\right) + \left(1 - y^{(i)}\right) h_\theta(x^{(i)})}{h_\theta(x^{(i)})\left(1 - h_\theta(x^{(i)})\right)} = \frac{-y^{(i)} + y^{(i)} h_\theta + h_\theta - y^{(i)} h_\theta}{h_\theta(x^{(i)})\left(1 - h_\theta(x^{(i)})\right)} = \frac{h_\theta(x^{(i)}) - y^{(i)}}{h_\theta(x^{(i)})\left(1 - h_\theta(x^{(i)})\right)} \] Now apply the chain rule with the derivative of \(\sigma(\theta^T x^{(i)})\) from Lemma 1.1: \[ \begin{aligned} \frac{\partial \ell_i}{\partial \theta_j} &= \frac{\partial \ell_i}{\partial h_\theta(x^{(i)})} \cdot \frac{\partial h_\theta(x^{(i)})}{\partial \theta_j} \\ &= \left[\frac{h_\theta(x^{(i)}) - y^{(i)}}{h_\theta(x^{(i)})\left(1 - h_\theta(x^{(i)})\right)}\right] \cdot \left[h_\theta(x^{(i)})\left(1 - h_\theta(x^{(i)})\right) x_j^{(i)}\right] \end{aligned} \] Notice the miraculous cancellation! The non-linear sigmoid denominator cancels out identically with the sigmoid derivative: \[ \frac{\partial \ell_i}{\partial \theta_j} = \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} \] Summing over all \(m\) observations and multiplying by \(\frac{1}{m}\) completes the proof: \[ \frac{\partial J(\theta)}{\partial \theta_j} = \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} \quad \blacksquare \]
The Remarkable Linear-Logistic Coincidence (Slide 5) The resulting gradient descent update rule for logistic regression is: \[ \theta_j := \theta_j - \alpha \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} \quad \text{simultaneously for all } j = 0, \dots, n \] Critical Insight: As highlighted in Slide 5 ("Algorithm looks identical to linear regression!"), the algebraic formula for the gradient update appears completely identical to Ordinary Least Squares!

However, the underlying mathematical algorithms are profoundly different:
  • In Linear Regression: \(h_\theta(x) = \theta^T x\) (an unbounded affine hyperplane).
  • In Logistic Regression: \(h_\theta(x) = \frac{1}{1 + e^{-\theta^T x}}\) (a non-linear probability mapping bounded in \((0, 1)\)).
This structural symmetry is not an accidental coincidence; it is a universal property of Generalized Linear Models (GLMs) operating under canonical link functions (explored in Lecture 18).

3. Linear and Non-Linear Decision Boundaries

A. Worked Numerical Example: Linear Decision Boundary (Slide 6)

Consider a 2D feature space \(x = [x_1, x_2]^T\) with model hypothesis: \[ h_\theta(x) = g(\theta_0 + \theta_1 x_1 + \theta_2 x_2) \] Suppose optimization on training data \(\{(x^{(i)}, y^{(i)})\}_{i=1}^m\) yields the parameter vector: \[ \theta = \begin{bmatrix} \theta_0 \\ \theta_1 \\ \theta_2 \end{bmatrix} = \begin{bmatrix} -3 \\ 1 \\ 1 \end{bmatrix} \] Applying a classification threshold of \(\tau = 0.5\): \[ \text{Predict } y = 1 \iff h_\theta(x) \ge 0.5 \iff \theta^T x \ge 0 \iff -3 + x_1 + x_2 \ge 0 \iff x_1 + x_2 \ge 3 \] \[ \text{Predict } y = 0 \iff h_\theta(x) < 0.5 \iff \theta^T x < 0 \iff -3 + x_1 + x_2 < 0 \iff x_1 + x_2 < 3 \] The Decision Boundary is the 1D line: \[ x_1 + x_2 = 3 \implies x_2 = -x_1 + 3 \] This line intersects the axes at \((3, 0)\) and \((0, 3)\). Any point with \(x_1 + x_2 > 3\) (e.g., \((2, 2)\)) is classified as \(y = 1\), and any point below (e.g., \((1, 1)\)) is classified as \(y = 0\).

B. Non-Linear Decision Boundaries via Feature Transformations (Slide 7)

When classes are arranged concentrically (e.g., positive points clustered near the origin surrounded by a ring of negative points), they are linearly non-separable in the original space \([x_1, x_2]\):

Circular Boundary Derivation (Slide 7)

Not linearly separable with a linear boundary \(\xrightarrow{\text{transformation}}\) Linearly separable in the higher-dimensional feature space

Define the non-linear feature mapping: \[ \phi(x_1, x_2) = \begin{bmatrix} 1 \\ x_1^2 \\ x_2^2 \end{bmatrix} \] and parameter weight vector \(w = [-R^2, 1, 1]^T\). The inner product becomes: \[ w^T \phi(x) = -R^2 + x_1^2 + x_2^2 \] Setting the decision boundary \(w^T \phi(x) = 0\): \[ x_1^2 + x_2^2 = R^2 \] This defines a circle of radius \(R\):
  • Predict \(y = 1\) if \(x_1^2 + x_2^2 > R^2\) (points exterior to the circle).
  • Predict \(y = 0\) if \(x_1^2 + x_2^2 < R^2\) (points interior to the circle).
While circular in the raw feature coordinates \((x_1, x_2)\), the decision boundary is strictly a linear hyperplane in the transformed feature space \((z_1 = x_1^2, z_2 = x_2^2)\)!

By expanding into higher-order polynomials \(P_\theta(x)\): \[ h_\theta(x) = \sigma\left(\theta_0 + \theta_1 x_1 + \theta_2 x_2 + \theta_3 x_1 x_2 + \theta_4 x_1^2 + \theta_5 x_2^2 + \dots\right) \] the model can delineate arbitrarily complex, multi-lobed decision contours (higher-order polynomial decision boundaries).

4. The Probabilistic View: Bernoulli Likelihood & Equivalence to MLE

A. Bernoulli Likelihood Representation (Slide 8)

In probabilistic machine learning, the binary target \(y \in \{0, 1\}\) given input \(x\) is modeled as a Bernoulli random variable: \[ y \mid x \sim \text{Bernoulli}\left(p = \sigma(w^T x + b)\right) \] where \(w^T x + b \equiv \theta^T x\). The probability mass function (PMF) is: \[ P(y = k \mid x; \theta) = \begin{cases} p & \text{if } k = 1 \\ 1 - p & \text{if } k = 0 \end{cases} \] The quantity \(a = w^T x + b\) represents the log-odds (logit): \[ a = \log\left(\frac{p}{1 - p}\right) \implies p = \sigma(a) = \frac{1}{1 + e^{-a}} \]

B. Maximum Likelihood Estimation Equivalence (Slides 9–11)

Assuming the \(m\) training examples \(\{(x^{(i)}, y^{(i)})\}_{i=1}^m\) are independent and identically distributed (i.i.d.): \[ P_\theta(y \mid X) = \prod_{i=1}^m P_\theta(y^{(i)} \mid x^{(i)}) = \prod_{i=1}^m \left[h_\theta(x^{(i)})\right]^{y^{(i)}} \left[1 - h_\theta(x^{(i)})\right]^{1 - y^{(i)}} \] Taking the natural logarithm yields the log-likelihood function \(\ell(\theta) = \log P_\theta(y \mid X)\): \[ \ell(\theta) = \sum_{i=1}^m \left[ y^{(i)} \log\left(h_\theta(x^{(i)})\right) + \left(1 - y^{(i)}\right) \log\left(1 - h_\theta(x^{(i)})\right) \right] \]

Theorem 4.1 (Equivalence of MLE and Cross-Entropy Minimization, Slide 11)

Under the assumption of independent Bernoulli observations for \(y\), the Maximum Likelihood Estimate (MLE) for parameter \(\theta\) is mathematically identical to minimizing the cross-entropy cost function.

Maximizing the log-likelihood is mathematically identical to minimizing the negative log-likelihood: \[ \hat{\theta}_{\text{MLE}} = \arg\max_\theta \ell(\theta) = \arg\min_\theta \left[ -\frac{1}{m} \ell(\theta) \right] = \arg\min_\theta J(\theta) \] Thus, cross-entropy loss is not a heuristic; it is the exact negative log-likelihood under Bernoulli sampling.

5. Multiclass Generalization: One-vs-All (One-vs-Rest)

Many real-world classification problems involve \(K > 2\) discrete mutually exclusive categories (Slide 12):

  • Email Categorization (\(K = 4\)): Work (\(y=0\)), Friends (\(y=1\)), Family (\(y=2\)), Hobby (\(y=3\)).
  • Medical Diagnostics (\(K = 3\)): Healthy (\(y=0\)), Common Cold (\(y=1\)), Influenza (\(y=2\)).
  • Meteorology (\(K = 4\)): Sunny (\(0\)), Cloudy (\(1\)), Rain (\(2\)), Snow (\(3\)).

A. The One-vs-All (OvA) Heuristic (Slides 13–15)

The simplest strategy to extend binary logistic regression to \(K\) classes is One-vs-All (OvA):

Algorithm 5.1 (One-vs-All Classification) Given a training set with targets \(y \in \{1, 2, \dots, K\}\):
  1. Train \(K\) independent binary logistic regression classifiers: \[ h_\theta^{(k)}(x) = P(y = k \mid x; \theta^{(k)}) \quad \text{for } k = 1, 2, \dots, K \] where classifier \(k\) is trained by relabeling class \(k\) as positive (\(y=1\)) and all other \(K-1\) classes combined as negative (\(y=0\)).
  2. For a novel query sample \(x_{\text{test}}\), evaluate all \(K\) classifiers simultaneously.
  3. Assign the sample to the class with the highest predicted probability: \[ \hat{y}_{\text{test}} = \arg\max_{k \in \{1, \dots, K\}} h_\theta^{(k)}(x_{\text{test}}) \]

6. Softmax Regression (Multinomial Logistic Regression)

While One-vs-All decomposes multiclass into \(K\) independent binary tasks, Softmax Regression (generalized logistic regression for \(K > 2\) classes) formulates a unified, globally normalized categorical distribution (Slides 16–17).

A. Softmax Hypothesis Formulation (Slide 16)

For \(K\) classes, we maintain a separate parameter weight vector \(\theta^{(k)} \in \mathbb{R}^{n+1}\) for each class, stacked as columns in the parameter matrix: \[ \Theta = \begin{bmatrix} \theta^{(1)} & \theta^{(2)} & \dots & \theta^{(K)} \end{bmatrix} \in \mathbb{R}^{(n+1) \times K} \] The hypothesis computes the posterior probability distribution over all \(K\) classes: \[ h_\Theta(x) = \begin{bmatrix} P(y = 1 \mid x; \Theta) \\ P(y = 2 \mid x; \Theta) \\ \vdots \\ P(y = K \mid x; \Theta) \end{bmatrix} \in \mathbb{R}^K \] The conditional probability for class \(j\) is given by the Softmax function: \[ h_\Theta^{(j)}(x) = \frac{\exp\left({\theta^{(j)}}^T x\right)}{\sum_{k=1}^K \exp\left({\theta^{(k)}}^T x\right)} \] Properties:

  • Positivity: \(h_\Theta^{(j)}(x) > 0\) for all \(j\).
  • Conservation of Probability: \(\sum_{j=1}^K h_\Theta^{(j)}(x) = 1\).
Canonical Application: MNIST handwritten digit recognition (\(K = 10\) classes for digits \(0, \dots, 9\)).

B. Categorical Cross-Entropy Cost Function (Slide 17)

Definition 6.1 (Categorical Cross-Entropy Loss) Let \(\mathbf{1}\{\cdot\}\) be the indicator function (\(\mathbf{1}\{\text{True}\} = 1\) and \(\mathbf{1}\{\text{False}\} = 0\)). The multiclass cross-entropy cost function is: \[ J(\Theta) = -\frac{1}{m} \sum_{i=1}^m \sum_{j=1}^K \mathbf{1}\left\{y^{(i)} = j\right\} \log \left( \frac{\exp\left({\theta^{(j)}}^T x^{(i)}\right)}{\sum_{k=1}^K \exp\left({\theta^{(k)}}^T x^{(i)}\right)} \right) \] This is the generalized negative log-likelihood of the Categorical distribution: \[ P(y \mid x, \Theta) \sim \text{Categorical}(p_1, p_2, \dots, p_K), \quad \text{where } p_K = 1 - \sum_{i=1}^{K-1} p_i \]
Worked Classification Example (Slide 17) Suppose a 4-class classifier evaluates a test input \(x_{\text{test}}\) and produces: \[ h_\Theta(x_{\text{test}}) = \begin{bmatrix} 0.80 \\ 0.10 \\ 0.05 \\ 0.05 \end{bmatrix} \] Since class 1 has probability \(0.80 > 0.10, 0.05\), the model decides: \[ \hat{y}_{\text{test}} = 1 \]

7. The Overfitting Pathology & Foundations of Regularization

A. The Core Mechanism of Overfitting (Slides 18–20)

The central dilemma of statistical learning is that an algorithm optimizes parameters to minimize empirical loss on the training set, but our ultimate objective is performance on unseen future data.

Motivating Toy Example: Coin Toss Maximum Likelihood (Slide 19) Suppose we wish to estimate the probability of flipping heads for a coin. We toss it \(N = 3\) times and observe: \[ \text{Heads, Heads, Heads} \implies N_1 = 3, \; N_0 = 0 \] The Maximum Likelihood Estimate is: \[ \theta_{\text{MLE}} = \frac{N_1}{N_0 + N_1} = \frac{3}{3 + 0} = 1.0 \] If we adopt this unregularized model, we predict that all future coin tosses will be heads with 100% certainty. This conclusion is absurd because \(N=3\) is far too small a sample to conclude the coin has two heads.

Theoretical Lesson (Slide 20): When a model has excessive capacity relative to the available data, it places all probability mass on the empirical sample, perfectly memorizing noise and failing completely to generalize to novel samples.

B. The Bias-Variance Spectrum in Regression & Classification (Slides 22–23)

Slide 22 and Slide 23 illustrate the spectrum across linear regression and logistic regression:

Regime Linear Regression Example Logistic Regression Boundary Error Characteristic
Underfitting \(h(x) = \theta_0 + \theta_1 x\) (straight line) Linear line \(g(\theta_0 + \theta_1 x_1 + \theta_2 x_2)\) High Bias: Model is too rigid to capture true underlying curve.

C. Addressing Overfitting (Slides 24–25)

Two primary strategies exist:

  1. Dimensionality Reduction / Feature Selection: Manually prune features or employ automated subset selection algorithms. Disadvantage: potentially discards useful residual predictive signals.
  2. Regularization: Retain all \(n\) features, but penalize the magnitude of parameters \(\theta_j\). This shrinks weights smoothly toward zero, enforcing simplicity without completely discarding features.

8. \(L_2\) Regularized Cost Function & Asymptotic Shrinkage Dynamics

A. Penalization Intuition: Shrinking Specific Coefficients (Slides 26–27)

Suppose we have a high-order polynomial \(h_\theta(x) = \theta_0 + \theta_1 x + \theta_2 x^2 + \theta_3 x^3 + \theta_4 x^4\). If we artificially modify the cost function: \[ \min_\theta \frac{1}{2m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right)^2 + 1000\,\theta_3^2 + 1000\,\theta_4^2 \] To minimize the total cost, the optimization algorithm will be heavily penalized unless \(\theta_3 \approx 0\) and \(\theta_4 \approx 0\). As \(\theta_3, \theta_4 \to 0\), the higher-order terms vanish, leaving approximately the simple quadratic model \(h_\theta(x) \approx \theta_0 + \theta_1 x + \theta_2 x^2\), which eliminates the extreme wild oscillations.

B. The General \(L_2\) Regularized Cost Function (Slides 28–29)

Definition 8.1 (\(L_2\) Regularized Linear Regression / Ridge) When we do not know in advance which features are noisy, we penalize all parameters uniformly: \[ J(\theta) = \frac{1}{2m} \left[ \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right)^2 + \lambda \sum_{j=1}^n \theta_j^2 \right] \] where \(\lambda \ge 0\) is the regularization hyperparameter.
Crucial Mathematical Convention: The Bias Term \(\theta_0\) is NOT Regularized! (Slide 28) Notice the summation index in the penalty term: \[ \lambda \sum_{j=1}^n \theta_j^2 \quad (\text{notice } j \text{ starts from } 1, \text{ NOT } 0!) \] The intercept/bias parameter \(\theta_0\) represents the baseline level or global average of \(y\) when all features are zero. Penalizing \(\theta_0\) would force the regression line to pass near the origin \((0, 0)\), which is an arbitrary artifact of coordinate shifts and harms predictive accuracy. By convention, \(\theta_0\) is strictly unpenalized.

C. Asymptotic Shrinkage & The Extreme \(\lambda\) Pathology (Slides 30–31)

What happens if the practitioner sets \(\lambda\) to an excessively large value, e.g., \(\lambda = 10^{10}\)?

  • The penalty term \(\lambda \sum_{j=1}^n \theta_j^2\) completely dominates the data-fitting term \(\frac{1}{2m} \sum (h_\theta(x^{(i)}) - y^{(i)})^2\).
  • The optimizer forces all regularized weights to zero: \[ \theta_1 \approx 0, \; \theta_2 \approx 0, \; \dots, \; \theta_n \approx 0 \]
  • The resulting learned hypothesis collapses to a horizontal line (Slide 31): \[ h_\theta(x) = \theta_0 = \bar{y} \]
  • Result: Severe Underfitting (High Bias). The model fails to capture any relationship whatsoever with the input features.

D. Comparison of Regularization Norms (Slide 30)

Geometry of Contours Spherical / circular quadratic penalty Diamond / sharp rhomboid penalty
