1. Prediction Confidence & The Concept of Margins

Recall the logistic regression hypothesis: \[ h_\theta(x) = \sigma(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}} \] The standard decision threshold classifies an input as follows: \[ \begin{aligned} h_\theta(x) \ge 0.5 &\iff \theta^T x \ge 0 \implies \hat{y} = 1 \\ h_\theta(x) < 0.5 &\iff \theta^T x < 0 \implies \hat{y} = 0 \text{ (or } -1\text{)} \end{aligned} \]

Geometric Intuition: High Confidence Class Boundaries

Consider fitting a classifier where for every positive sample (\(y^{(i)}=1\)), we obtain \(\theta^T x^{(i)} \gg 0\), and for every negative sample (\(y^{(i)}=-1\)), we obtain \(\theta^T x^{(i)} \ll 0\). Under such conditions, prediction confidence is robustly maximized:

A sample that lies far away from the separating boundary (\(|\theta^T x| \gg 0\)) is classified with very high certainty. Even under measurement noise or perturbations, its predicted class remains stable. Conversely, a sample situated dangerously close to the boundary (\(|\theta^T x| \approx 0\)) has very low confidence; the slightest variation in parameters or input features can flip its classification. This motivates designing a classifier that explicitly pushes the decision boundary as far away from all data points as possible.

2. Geometry of Separating Hyperplanes

Throughout Support Vector Machine theory, we adopt symmetric binary labels: \[ y \in \{-1, +1\} \] where \(y = +1\) denotes the positive class and \(y = -1\) denotes the negative class.

A hyperplane in a \(d\)-dimensional input space \(\mathbb{R}^d\) is defined by the set of points satisfying: \[ w_0 + w_1 x_1 + w_2 x_2 + \dots + w_d x_d = 0 \] Separating the intercept \(b = w_0\) from the weight vector \(w = [w_1, \dots, w_d]^T \in \mathbb{R}^d\), this becomes: \[ w^T x + b = 0 \] The classifier makes predictions via the sign function \(g(z)\): \[ h_{w, b}(x) = g(w^T x + b) = \begin{cases} +1 & \text{if } w^T x + b \ge 0 \\ -1 & \text{if } w^T x + b < 0 \end{cases} \] where \(g(z) = 1\) for \(z \ge 0\) and \(g(z) = -1\) for \(z < 0\).

Geometric Properties of the Hyperplane
  • Orthogonality: The weight vector \(w\) is strictly perpendicular (normal) to every line lying entirely within the hyperplane: if \(x_1, x_2\) satisfy \(w^T x_1 + b = 0\) and \(w^T x_2 + b = 0\), then \(w^T (x_1 - x_2) = 0\).
  • Signed Distance from Origin: The perpendicular distance from the origin \(\mathbf{0}\) to the hyperplane is given by \(\frac{b}{\|w\|_2}\).
  • Space Partitioning: The hyperplane partitions \(\mathbb{R}^d\) into two disjoint half-spaces: a positive region \(\{x : w^T x + b > 0\}\) and a negative region \(\{x : w^T x + b < 0\}\).

3. Functional Margin w.r.t. a Point and a Dataset

Definition 3.1: Functional Margin of an Example Given a training sample \((x^{(i)}, y^{(i)})\), the functional margin of the parameter pair \((w, b)\) with respect to this sample is: \[ \hat{\gamma}^{(i)} \triangleq y^{(i)} (w^T x^{(i)} + b) \]

Examining the sign and magnitude of \(\hat{\gamma}^{(i)}\):

  • If \(y^{(i)} = +1\), we want \(w^T x^{(i)} + b \gg 0\) for a confident positive prediction.
  • If \(y^{(i)} = -1\), we want \(w^T x^{(i)} + b \ll 0\) for a confident negative prediction.
  • In both cases, a correct prediction yields \(\hat{\gamma}^{(i)} > 0\), and large values represent confident correct classifications!
Definition 3.2: Functional Margin of a Dataset Given a training dataset \(S = \{(x^{(i)}, y^{(i)})\}_{i=1}^m\), the functional margin of the hyperplane \((w, b)\) with respect to \(S\) is the minimum functional margin across all training samples: \[ \hat{\gamma} \triangleq \min_{i=1, \dots, m} \hat{\gamma}^{(i)} = \min_{i=1, \dots, m} y^{(i)} (w^T x^{(i)} + b) \]
The Scale Invariance Flaw of Functional Margin

Notice that if we replace \(w\) with \(2w\) and \(b\) with \(2b\), the physical decision boundary does not change at all: \[ g(2w^T x + 2b) = g(2(w^T x + b)) = g(w^T x + b) \] Yet, the functional margin doubles: \(\hat{\gamma}^{(i)} \to 2\hat{\gamma}^{(i)}\)! By arbitrarily scaling \(w\) and \(b\) by a scalar \(k \to \infty\), we could make the functional margin arbitrarily large without changing the decision boundary by a millimeter. This shows that functional margin alone cannot serve as an objective function without a scale normalization constraint.

4. Geometric Margin: Rigorous Orthogonal Projection Derivation

To obtain a physically meaningful measure that is invariant to arbitrary parameter rescaling, we must compute the true Euclidean perpendicular distance from a data point to the hyperplane.

Derivation: Distance from Point \(x^{(i)}\) to Hyperplane \(w^T x + b = 0\) Let \(A\) be a positive training point \(x^{(i)}\) (so \(y^{(i)} = +1\)), and let \(B\) be the orthogonal projection of point \(A\) onto the hyperplane \(\mathcal{P} = \{x \mid w^T x + b = 0\}\).

The unit vector orthogonal to the hyperplane is \(\frac{w}{\|w\|_2}\). Since point \(B\) is obtained by moving from \(A\) in the direction perpendicular to the hyperplane by distance \(\gamma^{(i)}\): \[ B = x^{(i)} - \gamma^{(i)} \frac{w}{\|w\|_2} \] Since point \(B\) lies on the hyperplane, its coordinates must satisfy the hyperplane equation: \[ w^T B + b = 0 \implies w^T \left( x^{(i)} - \gamma^{(i)} \frac{w}{\|w\|_2} \right) + b = 0 \] Distributing the dot product: \[ w^T x^{(i)} - \gamma^{(i)} \frac{w^T w}{\|w\|_2} + b = 0 \] Recall that \(w^T w = \|w\|_2^2\). Therefore: \[ \frac{w^T w}{\|w\|_2} = \frac{\|w\|_2^2}{\|w\|_2} = \|w\|_2 \] Substituting this back gives: \[ w^T x^{(i)} - \gamma^{(i)} \|w\|_2 + b = 0 \implies \gamma^{(i)} \|w\|_2 = w^T x^{(i)} + b \] Solving for the distance \(\gamma^{(i)}\): \[ \gamma^{(i)} = \frac{w^T x^{(i)} + b}{\|w\|_2} = \left(\frac{w}{\|w\|_2}\right)^T x^{(i)} + \frac{b}{\|w\|_2} \]

Definition 4.1: The Geometric Margin Generalizing to both positive (\(y^{(i)} = +1\)) and negative (\(y^{(i)} = -1\)) samples: \[ \gamma^{(i)} \triangleq y^{(i)} \left( \left(\frac{w}{\|w\|_2}\right)^T x^{(i)} + \frac{b}{\|w\|_2} \right) = \frac{\hat{\gamma}^{(i)}}{\|w\|_2} \] The geometric margin of the dataset \(S\) is the minimum geometric margin across all training samples: \[ \gamma \triangleq \min_{i=1, \dots, m} \gamma^{(i)} \] Notice that multiplying \(w\) and \(b\) by any positive scalar \(k > 0\) multiplies both numerator and denominator by \(k\), leaving \(\gamma^{(i)}\) completely unchanged. The geometric margin is scale-invariant.

5. The Optimal Margin Classifier as Convex Quadratic Programming (QP)

Assuming the dataset is linearly separable, we wish to find the hyperplane \((w, b)\) that maximizes the geometric margin \(\gamma\): \[ \begin{aligned} \max_{\gamma, w, b} \quad & \gamma \\ \text{subject to} \quad & y^{(i)}(w^T x^{(i)} + b) \ge \gamma, \quad i = 1, \dots, m \\ & \|w\|_2 = 1 \end{aligned} \]

Eliminating the Non-Convex Norm Constraint

The constraint \(\|w\|_2 = 1\) is non-convex (it represents a spherical shell, not a convex ball). However, using the identity \(\gamma = \frac{\hat{\gamma}}{\|w\|}\), we can rewrite the optimization problem as: \[ \begin{aligned} \max_{\hat{\gamma}, w, b} \quad & \frac{\hat{\gamma}}{\|w\|_2} \\ \text{subject to} \quad & y^{(i)}(w^T x^{(i)} + b) \ge \hat{\gamma}, \quad i = 1, \dots, m \end{aligned} \] Here, the objective function \(\frac{\hat{\gamma}}{\|w\|}\) is non-convex. However, recall that the scale of \(w\) and \(b\) is completely arbitrary! We can introduce the scaling constraint that fixes the functional margin on the closest points to 1: \[ \hat{\gamma} = 1 \] Substituting \(\hat{\gamma} = 1\) into our objective, maximizing \(\frac{1}{\|w\|_2}\) is mathematically identical to minimizing \(\|w\|_2\), which is equivalent to minimizing \(\frac{1}{2}\|w\|_2^2\).

The Primal Optimization Problem for Hard-Margin SVM \[ \begin{aligned} \min_{w, b} \quad & \frac{1}{2} \|w\|_2^2 \\ \text{subject to} \quad & y^{(i)}(w^T x^{(i)} + b) \ge 1, \quad \forall i = 1, \dots, m \end{aligned} \]

This is a canonical Convex Quadratic Program (QP):

  • The objective \(\frac{1}{2} w^T w\) is strictly convex with a positive definite Hessian matrix \(I\).
  • The constraints \(1 - y^{(i)}(w^T x^{(i)} + b) \le 0\) are strictly affine (linear).
  • Standard QP solvers guarantee finding the unique global minimum!

6. Foundations of Lagrange Duality: Primal, Dual & KKT Conditions

While standard QP solvers can optimize the primal problem directly in \(O(d^3)\) time, formulating the Lagrange Dual unlocks two immense advantages:

  1. It reveals that the optimal classifier depends only on a tiny subset of data: the Support Vectors.
  2. It expresses the entire algorithm in terms of inner products \(\langle x^{(i)}, x^{(j)} \rangle\), directly enabling the Kernel Trick!

6.1 The General Primal Problem

Consider a general constrained optimization problem: \[ \begin{aligned} \min_w \quad & f(w) \\ \text{subject to} \quad & g_i(w) \le 0, \quad i = 1, \dots, k \\ & h_i(w) = 0, \quad i = 1, \dots, l \end{aligned} \] Define the Generalized Lagrangian: \[ \mathcal{L}(w, \alpha, \beta) = f(w) + \sum_{i=1}^k \alpha_i g_i(w) + \sum_{i=1}^l \beta_i h_i(w) \] where \(\alpha_i \ge 0\) and \(\beta_i \in \mathbb{R}\) are Lagrange multipliers.

The Primal Objective Function Define \(\theta_{\mathcal{P}}(w) \triangleq \max_{\alpha, \beta : \alpha_i \ge 0} \mathcal{L}(w, \alpha, \beta)\).

If \(w\) violates any constraint:

  • If \(g_i(w) > 0\), setting \(\alpha_i \to \infty\) makes \(\mathcal{L} \to \infty\).
  • If \(h_i(w) \ne 0\), choosing \(\beta_i\) with the same sign as \(h_i(w)\) and \(\beta_i \to \infty\) makes \(\mathcal{L} \to \infty\).

If \(w\) satisfies all constraints (\(g_i(w) \le 0, h_i(w) = 0\)), the maximum occurs when \(\alpha_i g_i(w) = 0\), so \(\theta_{\mathcal{P}}(w) = f(w)\). Hence: \[ \theta_{\mathcal{P}}(w) = \begin{cases} f(w) & \text{if } w \text{ is feasible} \\ +\infty & \text{otherwise} \end{cases} \] Therefore, the primal problem \(\min_w f(w)\) subject to constraints is identically: \[ p^* = \min_w \theta_{\mathcal{P}}(w) = \min_w \max_{\alpha \ge 0, \beta} \mathcal{L}(w, \alpha, \beta) \]

6.2 The Dual Problem & Duality Gap

Swapping the order of minimization and maximization yields the Dual Problem: \[ d^* = \max_{\alpha \ge 0, \beta} \theta_{\mathcal{D}}(\alpha, \beta) = \max_{\alpha \ge 0, \beta} \min_w \mathcal{L}(w, \alpha, \beta) \] Weak Duality: It is always true that: \[ d^* \le p^* \] (The maximum of a minimum is always less than or equal to the minimum of a maximum).

Strong Duality & The Karush-Kuhn-Tucker (KKT) Conditions If \(f\) and \(g_i\) are convex, \(h_i\) are affine, and the constraints are strictly feasible (Slater's condition: \(\exists w\) such that \(g_i(w) < 0 \; \forall i\)), then Strong Duality holds: \[ d^* = p^* \] Moreover, \(w^*\) and \((\alpha^*, \beta^*)\) are solutions to the primal and dual problems if and only if they satisfy the KKT conditions:
  1. Primal Feasibility: \(g_i(w^*) \le 0\) for \(i=1\dots k\), and \(h_i(w^*) = 0\) for \(i=1\dots l\).
  2. Dual Feasibility: \(\alpha_i^* \ge 0\) for \(i=1\dots k\).
  3. Stationarity: \(\nabla_w \mathcal{L}(w^*, \alpha^*, \beta^*) = \mathbf{0}\).
  4. Complementary Slackness: \[ \alpha_i^* g_i(w^*) = 0 \quad \text{for all } i = 1, \dots, k \]

7. Full Derivation of the SVM Dual Problem

Let us apply Lagrange duality to the SVM hard-margin primal problem: \[ \min_{w, b} \frac{1}{2} w^T w \quad \text{s.t.} \quad 1 - y^{(i)}(w^T x^{(i)} + b) \le 0, \quad i = 1 \dots m \] The Lagrangian is given by slide 25 (equation 21): \[ \mathcal{L}(w, b, \alpha) = \frac{1}{2} \|w\|^2 - \sum_{i=1}^m \alpha_i \left[ y^{(i)}(w^T x^{(i)} + b) - 1 \right] \]

Step 1: Minimizing \(\mathcal{L}\) with respect to \(w\) and \(b\) Setting the gradient with respect to \(w\) to zero: \[ \nabla_w \mathcal{L} = w - \sum_{i=1}^m \alpha_i y^{(i)} x^{(i)} = 0 \implies w = \sum_{i=1}^m \alpha_i y^{(i)} x^{(i)} \quad \text{(Equation 22)} \] Setting the partial derivative with respect to \(b\) to zero: \[ \frac{\partial \mathcal{L}}{\partial b} = -\sum_{i=1}^m \alpha_i y^{(i)} = 0 \implies \sum_{i=1}^m \alpha_i y^{(i)} = 0 \quad \text{(Equation 23)} \]
Step 2: Substituting \(w\) and \(\sum \alpha_i y^{(i)} = 0\) back into \(\mathcal{L}\) Substitute \(w = \sum_{i=1}^m \alpha_i y^{(i)} x^{(i)}\) into the Lagrangian: \[ \begin{aligned} \mathcal{L}(w, b, \alpha) &= \frac{1}{2} w^T w - \sum_{i=1}^m \alpha_i y^{(i)} w^T x^{(i)} - b \sum_{i=1}^m \alpha_i y^{(i)} + \sum_{i=1}^m \alpha_i \\ &= \frac{1}{2} \left(\sum_{i=1}^m \alpha_i y^{(i)} x^{(i)}\right)^T \left(\sum_{j=1}^m \alpha_j y^{(j)} x^{(j)}\right) - \sum_{i=1}^m \alpha_i y^{(i)} \left( \sum_{j=1}^m \alpha_j y^{(j)} x^{(j)} \right)^T x^{(i)} - b(0) + \sum_{i=1}^m \alpha_i \\ &= \frac{1}{2} \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j y^{(i)} y^{(j)} (x^{(i)})^T x^{(j)} - \sum_{i=1}^m \sum_{j=1}^m \alpha_i \alpha_j y^{(i)} y^{(j)} (x^{(i)})^T x^{(j)} + \sum_{i=1}^m \alpha_i \\ &= \sum_{i=1}^m \alpha_i - \frac{1}{2} \sum_{i=1}^m \sum_{j=1}^m y^{(i)} y^{(j)} \alpha_i \alpha_j \langle x^{(i)}, x^{(j)} \rangle \end{aligned} \]
Theorem 7.1: The SVM Dual Optimization Problem \[ \begin{aligned} \max_{\alpha} \quad & W(\alpha) = \sum_{i=1}^m \alpha_i - \frac{1}{2} \sum_{i=1}^m \sum_{j=1}^m y^{(i)} y^{(j)} \alpha_i \alpha_j \langle x^{(i)}, x^{(j)} \rangle \\ \text{subject to} \quad & \alpha_i \ge 0, \quad i = 1, \dots, m \\ & \sum_{i=1}^m \alpha_i y^{(i)} = 0 \end{aligned} \]

Crucial Insight: In this dual formulation, the data points \(x^{(i)}\) appear exclusively inside the pairwise inner product \(\langle x^{(i)}, x^{(j)} \rangle\). To kernelize the SVM, we simply substitute: \[ \langle x^{(i)}, x^{(j)} \rangle \longrightarrow K(x^{(i)}, x^{(j)}) \]

8. Support Vectors, Complementary Slackness & Recovering \(b^*\)

8.1 Sparsity of Support Vectors

Recall the KKT complementary slackness condition: \[ \alpha_i^* \left[ y^{(i)}((w^*)^T x^{(i)} + b^*) - 1 \right] = 0 \quad \forall i = 1, \dots, m \]

Key Property: Sparsity of Support Vectors

By the KKT complementary slackness condition \(\alpha_i^* [y^{(i)}(w^{*T} x^{(i)} + b^*) - 1] = 0\), non-zero dual coefficients exist only on active constraints:

  • If point \(x^{(i)}\) lies strictly outside the margin (\(y^{(i)}(w^T x^{(i)} + b) > 1\)), then the bracket is strictly positive, forcing \(\alpha_i^* = 0\)!
  • Therefore, \(\alpha_i^* > 0\) can occur only if \(y^{(i)}(w^T x^{(i)} + b) = 1\) — precisely the points lying directly on the margin boundaries!

To predict the class of a new query sample \(x\): \[ h_{w, b}(x) = \text{sign}\left( (w^*)^T x + b^* \right) = \text{sign}\left( \sum_{i \in \text{SV}} \alpha_i^* y^{(i)} \langle x^{(i)}, x \rangle + b^* \right) \] All training samples that are not Support Vectors contribute zero to the summation!

8.2 Recovering the Optimal Intercept \(b^*\)

Once \(\alpha^*\) and \(w^* = \sum_{i \in \text{SV}} \alpha_i y^{(i)} x^{(i)}\) are computed, slide 28 provides the closed-form calculation for \(b^*\): \[ b^* = -\frac{\max_{i: y^{(i)}=-1} (w^*)^T x^{(i)} + \min_{i: y^{(i)}=+1} (w^*)^T x^{(i)}}{2} \] This places the decision boundary exactly halfway between the closest positive and negative support vectors.

9. Soft-Margin SVM for Non-Separable Data & Box Constraints

If data is not linearly separable, or if we want to guard against sensitivity to outliers (as shown in slide 31 where a single outlier drastically shifts the separating line), we introduce slack variables \(\xi_i \ge 0\).

Soft-Margin Primal Problem (\(\ell_1\) Regularization) \[ \begin{aligned} \min_{w, b, \xi} \quad & \frac{1}{2} \|w\|^2 + C \sum_{i=1}^m \xi_i \\ \text{subject to} \quad & y^{(i)}(w^T x^{(i)} + b) \ge 1 - \xi_i, \quad i = 1, \dots, m \\ & \xi_i \ge 0, \quad i = 1, \dots, m \end{aligned} \]
Derivation of the Soft-Margin Dual Box Constraint The generalized Lagrangian with multipliers \(\alpha_i \ge 0\) and \(r_i \ge 0\) is (Slide 30): \[ \mathcal{L}(w, b, \xi, \alpha, r) = \frac{1}{2} w^T w + C \sum_{i=1}^m \xi_i - \sum_{i=1}^m \alpha_i \left[ y^{(i)}(w^T x^{(i)} + b) - 1 + \xi_i \right] - \sum_{i=1}^m r_i \xi_i \] Taking the partial derivative with respect to the slack variable \(\xi_i\): \[ \frac{\partial \mathcal{L}}{\partial \xi_i} = C - \alpha_i - r_i = 0 \implies \alpha_i = C - r_i \] Since the Lagrange multiplier \(r_i \ge 0\), this directly implies: \[ \alpha_i \le C \] Combining this with \(\alpha_i \ge 0\) yields the famous Box Constraint: \[ 0 \le \alpha_i \le C \quad \forall i = 1, \dots, m \]
Theorem 9.1: The Soft-Margin SVM Dual \[ \begin{aligned} \max_\alpha \quad & W(\alpha) = \sum_{i=1}^m \alpha_i - \frac{1}{2} \sum_{i,j=1}^m y^{(i)} y^{(j)} \alpha_i \alpha_j K(x^{(i)}, x^{(j)}) \\ \text{subject to} \quad & 0 \le \alpha_i \le C, \quad i = 1, \dots, m \\ & \sum_{i=1}^m \alpha_i y^{(i)} = 0 \end{aligned} \]
Diagnostic Summary: The Effect of Hyperparameter \(C\)

As highlighted on slide 34:

  • Large \(C\) (\(C \uparrow\)): High penalty on slacks \(\xi_i\). Margin is narrow. Fewer margin violations permitted \(\implies\) Fewer Support Vectors, Low Bias, High Variance (Risk of Overfitting).
  • Small \(C\) (\(C \downarrow\)): Low penalty on violations. Margin is wide. More points violate the margin \(\implies\) More Support Vectors, High Bias, Low Variance (Risk of Underfitting).

10. Multiclass Classification: One-vs-All (OvA)

SVM is inherently a binary classifier. When targets belong to \(K > 2\) classes (\(y \in \{1, 2, \dots, K\}\)), the canonical approach is One-vs-All (OvA), also called One-vs-Rest (OvR) (Slide 38):

  1. For each class \(k \in \{1, \dots, K\}\), train a binary SVM where samples from class \(k\) are labeled \(+1\) and all other samples from classes \(j \ne k\) are labeled \(-1\).
  2. This yields \(K\) distinct hyperplanes parameterized by \((\theta^{(1)}, \dots, \theta^{(K)})\).
  3. For an unseen test point \(x_{\text{test}}\), evaluate the continuous decision function under all \(K\) models and assign the class with the maximum confidence score: \[ \hat{y} = \arg\max_{k \in \{1, \dots, K\}} h_\theta^{(k)}(x_{\text{test}}) = \arg\max_{k \in \{1, \dots, K\}} \left( (\theta^{(k)})^T x_{\text{test}} \right) \]

11. Decision Guide: SVMs vs. Logistic Regression vs. Neural Networks

An essential engineering consideration is the direct correspondence between regularized models:

Parameter Equivalence: \(C \sim 1/\lambda\)

Comparing the objective functions of \(L_2\)-regularized Logistic Regression and soft-margin SVM reveals the reciprocal role of their hyperparameters:
In Logistic Regression, the cost is \(J(\theta) + \frac{\lambda}{2}\|\theta\|^2\). In SVM, the cost is \(\frac{1}{2}\|w\|^2 + C \sum \xi_i\). Thus: \[ C \longleftrightarrow \frac{1}{\lambda} \] A large \(C\) corresponds to weak regularization (\(\lambda \to 0\)), whereas a small \(C\) corresponds to heavy regularization (\(\lambda \to \infty\)).

Dimensionality Regime Typical Scale Recommended Model Engineering Rationale
\(n\) large relative to \(m\) \(n = 10,000, \; m = 10 \dots 1,000\) Logistic Regression or Linear SVM (no kernel) In high dimensions, data is already linearly separable. Non-linear kernels add severe risk of overfitting and waste computational resources.
\(n\) small, \(m\) intermediate \(n = 1 \dots 1,000, \; m = 10 \dots 10,000\) SVM with Gaussian (RBF) Kernel Gaussian kernel efficiently forms complex, highly non-linear boundaries. Sample size \(m\) is small enough that computing the \(m \times m\) Gram matrix is fast.
\(n\) small, \(m\) very large \(n = 1 \dots 1,000, \; m = 50,000 \dots 1,000,000+\) Manual Feature Engineering + Logistic Regression / Linear SVM Gaussian kernel SVM scales as \(O(m^2)\) in memory and \(O(m^3)\) in training time, becoming completely intractable for \(m > 50,000\). Manually adding polynomial features with a linear model scales as \(O(m)\).
Universal Alternative Any regime Deep Neural Networks Likely to perform well across all regimes, but may require more tuning, larger training times, and can get trapped in local optima due to non-convex loss surfaces.
