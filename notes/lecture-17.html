1. The Problem of Overfitting: Motivation & The Bias-Variance Tradeoff

In statistical learning, our fundamental objective is not merely to minimize the loss on historical data, but to achieve superior generalization performance on unseen test distributions. When model flexibility exceeds the information content of the training dataset, models succumb to overfitting.

Motivating Example: The 3-Coin-Toss Pathology

Consider flipping a coin 3 times and observing 3 Heads: \(\mathcal{D} = \{H, H, H\}\). The Maximum Likelihood Estimator (MLE) for the probability of landing Heads is: \[ \theta_{\text{MLE}} = \frac{3}{3} = 1.0 \] Under this unregularized MLE model, the predicted probability of ever observing Tails on the fourth flip is identically zero! The estimator has catastrophically overfitted to a miniature sample, confusing temporary empirical variance with immutable physical ground truth.

The identical pathology emerges across regression and classification:

  • Underfitting (High Bias): The model class is too simplistic to capture the true underlying data manifold (e.g., fitting a linear hypothesis \(y = \theta_0 + \theta_1 x\) to inherently parabolic data). Both training error and test error remain high.
  • Overfitting (High Variance): The hypothesis function contains excessive degrees of freedom (e.g., fitting a high-degree polynomial \(h_\theta(x) = \sum_{j=0}^{10} \theta_j x^j\) to a small collection of points). The curve contorts wildly to pass through every individual data point, memorizing stochastic noise rather than underlying patterns. Training error drops toward zero, while test error explodes!
Theorem 1.1 (The Bias-Variance Decomposition) Assume the true data generation process is \(y = f(x) + \varepsilon\), where \(\varepsilon\) is zero-mean noise with variance \(\sigma_\varepsilon^2\) independent of \(x\). For any estimator \(\hat{f}(x)\) trained on sample \(\mathcal{D}\), the expected test Mean Squared Error decomposes into three mutually orthogonal, non-negative components: \[ \mathbb{E}_\mathcal{D}\left[(y - \hat{f}(x))^2\right] = \underbrace{\left(\mathbb{E}_\mathcal{D}[\hat{f}(x)] - f(x)\right)^2}_{\text{Bias}^2(\hat{f}(x))} + \underbrace{\mathbb{E}_\mathcal{D}\left[\left(\hat{f}(x) - \mathbb{E}_\mathcal{D}[\hat{f}(x)]\right)^2\right]}_{\text{Variance}(\hat{f}(x))} + \underbrace{\sigma_\varepsilon^2}_{\text{Irreducible Noise}} \]

As model capacity increases, Bias decreases monotonically, but Variance increases rapidly. The optimal generalization performance occurs at the sweet spot minimizing their sum.

To combat overfitting, we have two fundamental strategies:

  1. Reduce the number of features: Manually discard predictors or run feature selection algorithms. However, discarding features risks throwing away valuable predictive signal.
  2. Regularization: Keep all \(n\) features, but systematically constrain or penalize the magnitude of the parameters \(\theta_j\). This proves exceptionally effective when we possess many features, each contributing a small amount toward predicting \(y\).

2. The Regularization Principle & Objective Formulation

Regularization modifies the optimization landscape by adding a complexity penalty to the empirical data loss: \[ \min_\theta \mathcal{L}(\theta; \lambda) = \frac{1}{m}\sum_{i=1}^m \ell\left(h_\theta(x^{(i)}), y^{(i)}\right) + \lambda \, C(\theta) \] where \(\ell\) is the per-sample loss (squared error for regression, log-loss for classification), \(C(\theta)\) is the parameter penalty function, and \(\lambda \ge 0\) is the regularization hyperparameter governing the tradeoff between training fidelity and model simplicity:

  • If \(\lambda = 0\), the penalty vanishes and we recover standard unregularized Maximum Likelihood / Least Squares.
  • If \(\lambda \to \infty\), the penalty dominates, forcing all penalized weights \(\theta_j \to 0\) (causing severe underfitting, e.g., collapsing linear regression to a horizontal flat line \(h_\theta(x) = \theta_0\)).
The Crucial Non-Penalization of Intercept \(\theta_0\)

By universal convention in machine learning and statistics, we never penalize the bias intercept \(\theta_0\): \[ C(\theta) = \sum_{j=1}^n \theta_j^2 \quad \text{or} \quad \sum_{j=1}^n |\theta_j| \] Penalizing \(\theta_0\) would artificially force the baseline prediction toward zero regardless of the target's physical scale (e.g., house prices centered around \(\$500{,}000\)). Penalties are strictly applied only to the directional feature weights \(j = 1, \dots, n\).

3. Ridge Regression (\(L_2\) Regularization)

In Ridge Regression (Tikhonov regularization), the complexity penalty is proportional to the squared Euclidean \(L_2\) norm of the non-intercept parameter vector: \[ J_{\text{Ridge}}(\theta) = \frac{1}{2m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right)^2 + \frac{\lambda}{2m} \sum_{j=1}^n \theta_j^2 \] Notice the normalizer \(\frac{1}{2m}\) applied to both the sum of squared errors and the penalty term, keeping their relative scale balanced regardless of dataset size \(m\).

4. Ridge Optimization: Weight Decay & Analytical Invertibility

First-Order Optimization: Weight Decay Update Differentiating \(J_{\text{Ridge}}(\theta)\) with respect to each parameter yields:
  • For the unpenalized intercept \(\theta_0\): \[ \frac{\partial J}{\partial \theta_0} = \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_0^{(i)} \implies \theta_0 := \theta_0 - \alpha \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_0^{(i)} \]
  • For each feature weight \(\theta_j\) (\(j = 1, \dots, n\)): \[ \frac{\partial J}{\partial \theta_j} = \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} + \frac{\lambda}{m} \theta_j \] Yielding the gradient descent step: \[ \theta_j := \theta_j - \alpha \left[ \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} + \frac{\lambda}{m} \theta_j \right] \] Rearranging terms reveals the profound weight decay phenomenon: \[ \theta_j := \theta_j \left( 1 - \alpha \frac{\lambda}{m} \right) - \alpha \frac{1}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} \] Because \(\alpha > 0\) and \(\lambda > 0\), the coefficient \(\left( 1 - \alpha \frac{\lambda}{m} \right)\) is strictly less than 1 (for instance, \(1 - 0.01 = 0.99\)). On every single gradient iteration, \(\theta_j\) is first shrunk toward zero by multiplying with \(0.99\) before taking the standard loss gradient step!
Theorem 4.1 (Regularized Normal Equation & Guaranteed Invertibility) Setting the matrix gradient \(\nabla_\theta J_{\text{Ridge}}(\theta) = \mathbf{0}\) yields the closed-form analytical solution: \[ \theta^* = \left( X^T X + \lambda L \right)^{-1} X^T y \] where \(L\) is the \((n+1) \times (n+1)\) diagonal matrix with a zero in the first diagonal entry (corresponding to unpenalized \(\theta_0\)) and ones elsewhere: \[ L = \begin{bmatrix} 0 & 0 & 0 & \dots & 0 \\ 0 & 1 & 0 & \dots & 0 \\ 0 & 0 & 1 & \dots & 0 \\ \vdots & \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & 0 & \dots & 1 \end{bmatrix}_{(n+1) \times (n+1)} \] For example, when \(n = 2\), the regularization matrix is: \[ L = \begin{bmatrix} 0 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} \]
The Problem of Non-Invertibility (Collinear Features & High Dimensions):

In unregularized OLS, the Normal Equation requires computing \((X^T X)^{-1}\). When features are collinear or high-dimensional:
"Suppose \(m \le n\) (#examples \(\le\) #features) or we have linearly dependent features (\(m \ll n\)). In this case, \(X^T X\) is singular (non-invertible / singular) because its rank is at most \(m < n+1\)."
If \(\lambda > 0\), adding \(\lambda L\) injects strictly positive values into all diagonal entries except the first. Provided \(X\) has an intercept column of ones and no all-zero columns, the matrix \((X^T X + \lambda L)\) is strictly positive definite and provably invertible! Ridge regression completely solves the numerical instability of ill-conditioned and rank-deficient design matrices.

5. Regularized Logistic Regression

Regularization is equally vital in classification. For binary classification with \(h_\theta(x) = \sigma(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}}\), the \(L_2\)-regularized cost function is: \[ J_{\text{reg}}(\theta) = -\frac{1}{m} \sum_{i=1}^m \left[ y^{(i)} \ln\left(h_\theta(x^{(i)})\right) + \left(1 - y^{(i)}\right) \ln\left(1 - h_\theta(x^{(i)})\right) \right] + \frac{\lambda}{2m} \sum_{j=1}^n \theta_j^2 \] The gradient descent update rules parallel the linear regression case exactly: \[ \theta_0 := \theta_0 - \frac{\alpha}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_0^{(i)} \] \[ \theta_j := \theta_j \left( 1 - \alpha \frac{\lambda}{m} \right) - \frac{\alpha}{m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right) x_j^{(i)} \quad (j \ge 1) \] Stabilizing Effect: When classes are linearly separable, unregularized logistic regression drives \(\|\theta\| \to \infty\) in an attempt to saturate \(\sigma(\theta^T x) \in \{0, 1\}\). Adding \(\frac{\lambda}{2m}\sum \theta_j^2\) bounds the parameter norms, preventing catastrophic numerical overflow and yielding well-calibrated posterior probabilities.

6. Lasso Regression (\(L_1\) Regularization) & The Bayesian MAP Perspective

The Lasso (Least Absolute Shrinkage and Selection Operator) replaces the squared penalty with the \(L_1\) absolute value norm: \[ J_{\text{Lasso}}(\theta) = \frac{1}{2m} \sum_{i=1}^m \left(h_\theta(x^{(i)}) - y^{(i)}\right)^2 + \frac{\lambda}{2m} \sum_{j=1}^n |\theta_j| \]

Sparsity & The \(L_0\) Connection

The ideal mathematical formulation of feature selection is the \(L_0\) pseudo-norm, which counts the number of non-zero parameters: \(\|\theta\|_0 = \sum_{j=1}^n \mathbf{1}\{\theta_j \ne 0\}\). However, minimizing an \(L_0\) penalty is NP-hard (combinatorial search over \(2^n\) feature subsets).

The \(L_1\) norm \(\sum |\theta_j|\) is the tightest convex relaxation of the \(L_0\) norm. As established in the slides: \[ \text{sparsity} \longleftarrow L_0\text{-norm} \approx L_1\text{-norm} \] Lasso drives irrelevant parameters to be identically zero: \(\theta_j^* = 0\), performing continuous, convex, automatic feature selection!

The Bayesian MAP Perspective

From this Bayesian standpoint:
"Instead of a point estimate for \(\theta\), a probability distribution over \(\theta\) is inferred to model parametric uncertainty: \[ \theta \sim p(\theta) \quad (\theta \text{ is a random vector with a prior distribution}) \] \[ \theta_{\text{MAP}} = \arg\max_\theta p(\theta | X, y) = \arg\max_\theta \left[ p(y | X; \theta) p(\theta) \right] = \arg\max_\theta \left[ \ln p(y | X; \theta) + \ln p(\theta) \right] \] "

Taking the negative log yields an objective equivalent to empirical loss plus regularization:

  • Gaussian Prior \(\implies L_2\) (Ridge): If we place an i.i.d. Gaussian prior \(\theta_j \sim \mathcal{N}(0, \tau^2)\) on the weights: \[ \ln p(\theta) = -\frac{1}{2\tau^2} \sum_{j=1}^n \theta_j^2 - \text{const} \iff \text{Penalty: } \frac{\lambda}{2} \|\theta\|_2^2 \quad \text{with } \lambda = \frac{\sigma^2}{\tau^2} \]
  • Laplace Prior \(\implies L_1\) (Lasso): If we place an i.i.d. Laplace (double-exponential) prior \(p(\theta_j) = \frac{1}{2b}\exp(-|\theta_j|/b)\): \[ \ln p(\theta) = -\frac{1}{b} \sum_{j=1}^n |\theta_j| - \text{const} \iff \text{Penalty: } \lambda \|\theta\|_1 \quad \text{with } \lambda = \frac{\sigma^2}{b} \] The sharp, non-differentiable peak of the Laplace density at \(\theta_j = 0\) imposes strong probabilistic mass precisely on zero, thereby enforcing sparsity onto the parameter vector!

7. Geometric Intuition: Why \(L_1\) Enforces Exact Zero Sparsity

Using Lagrange duality, Ridge and Lasso can be formulated as constrained optimization problems:

  • Ridge Constraint: \(\min_\theta \sum (h_\theta(x) - y)^2 \quad \text{subject to } \sum_{j=1}^n \theta_j^2 \le C\) (Hypersphere / Disk).
  • Lasso Constraint: \(\min_\theta \sum (h_\theta(x) - y)^2 \quad \text{subject to } \sum_{j=1}^n |\theta_j| \le C\) (Cross-polytope / Diamond).
The Geometry in Two Dimensions (\(\theta_1, \theta_2\))

Imagine the expanding elliptical level curves of the unconstrained OLS residual sum of squares centered at \(\hat{\theta}_{\text{OLS}}\):

  • Ridge (Smooth Circle): The constraint boundary \(\theta_1^2 + \theta_2^2 = C\) has continuous curvature everywhere. Tangential contact between the expanding ellipse and the circle almost always occurs at an off-axis point where both \(\theta_1 \ne 0\) and \(\theta_2 \ne 0\). Coefficients are shrunk smoothly, but almost never set exactly to zero.
  • Lasso (Sharp Diamond Vertices): The constraint region \(|\theta_1| + |\theta_2| \le C\) is a diamond whose sharp corners lie exactly on the coordinate axes (where \(\theta_1 = 0\) or \(\theta_2 = 0\)). Because corners project outward, the expanding elliptical contour is overwhelmingly likely to touch a corner first! At the corner contact point, one of the coordinates is identically zero (\(\theta_j = 0\)).

8. Model Evaluation & Cross-Validation

How do we select the optimal regularization hyperparameter \(\lambda\)? Setting \(\lambda\) using training error is useless because training error is always minimized at \(\lambda = 0\). We must evaluate out-of-sample generalization.

Slide 24 Evaluation Blueprint: Train / Validation / Test Partition

As detailed on Slide 24, a representative dataset of \(N = 1000\) samples is partitioned into three disjoint subsets:

  • Training Set (800 samples): Used exclusively to optimize parameter weights \(\theta\) for a fixed candidate value of \(\lambda\).
  • Validation Set (100 samples): Used to evaluate performance across a logarithmic grid of \(\lambda\) values (e.g., \(\lambda \in \{10^{-4}, 10^{-3}, \dots, 10^3\}\)) and select the optimal hyperparameter \(\lambda^*\).
  • Test Set (100 samples): Held out completely in a vault and evaluated only once at the conclusion of the study to obtain an unbiased estimate of real-world generalization error. (Never tune \(\lambda\) on the test set!).
K-Fold Cross-Validation (5-Fold Scheme)

When data is scarce, partitioning a static validation set sacrifices 10–20% of training data. \(K\)-Fold Cross-Validation maximizes data utilization:

  • The 1000 samples are split into \(K = 5\) equal folds of \(200\) samples each.
  • In each of the 5 iterations:
    • Hold out 1 fold (200 samples) as the test/validation fold.
    • Train the model on the remaining 4 folds combined (\(4 \times 200 = 800\) training samples).
    • Compute the validation error on the held-out 200 samples.
  • Average the validation error across all 5 folds: \[ \text{CV}_{(K)}(\lambda) = \frac{1}{K} \sum_{k=1}^K \text{MSE}_k(\lambda) \]
  • Select the hyperparameter \(\lambda^* = \arg\min_\lambda \text{CV}_{(K)}(\lambda)\), and finally retrain the model on the complete dataset of 1000 samples using \(\lambda^*\).
