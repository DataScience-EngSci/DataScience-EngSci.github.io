1. Multiparameter MLE: Gaussian Distribution \(\mathcal{N}(\mu, \sigma^2)\)

In many empirical models, we must simultaneously estimate multiple parameters. Consider an i.i.d. random sample \(X_1, X_2, \dots, X_n \sim \mathcal{N}(\mu, \sigma^2)\), where the parameter vector is \(\boldsymbol{\theta} = (\mu, \sigma^2)^T\).

The Normal Density and Likelihood The probability density function of each observation is: \[ f(x_i; \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x_i - \mu)^2}{2\sigma^2}\right) \] The joint likelihood across the \(n\) independent observations is: \[ L(\mu, \sigma^2) = \prod_{i=1}^n \left(2\pi\sigma^2\right)^{-1/2} \exp\left(-\frac{(x_i - \mu)^2}{2\sigma^2}\right) = \left(2\pi\sigma^2\right)^{-n/2} \exp\left(-\frac{1}{2\sigma^2}\sum_{i=1}^n (x_i - \mu)^2\right) \] Taking the natural logarithm: \[ \ell(\mu, \sigma^2) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i - \mu)^2 \]
Derivation: Simultaneous Normal MLEs To maximize \(\ell(\mu, \sigma^2)\), we compute the partial derivatives and equate them to zero:

1. Solving for \(\mu\):

\[ \frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum_{i=1}^n (x_i - \mu) = 0 \implies \sum_{i=1}^n x_i - n\mu = 0 \implies \hat{\mu}_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n X_i = \bar{X} \]

2. Solving for \(\sigma^2\): Treating \(\sigma^2\) as a single variable \(v = \sigma^2\):

\[ \frac{\partial \ell}{\partial v} = -\frac{n}{2v} + \frac{1}{2v^2}\sum_{i=1}^n (x_i - \hat{\mu})^2 = 0 \] Multiplying through by \(2v^2\): \[ -n v + \sum_{i=1}^n (x_i - \bar{X})^2 = 0 \implies \hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2 \]

2. Finite-Sample Bias of the Normal Variance MLE

A vital pedagogical point that every data scientist must understand: Maximum Likelihood Estimators are NOT guaranteed to be unbiased in finite samples!

Theorem 2.1 (Finite-Sample Bias of \(\hat{\sigma}^2_{\text{MLE}}\)) From Lecture 05's derivation of Bessel's correction: \[ E\left[\hat{\sigma}^2_{\text{MLE}}\right] = E\left[\frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2\right] = \frac{n - 1}{n}\sigma^2 = \sigma^2 - \frac{\sigma^2}{n} \neq \sigma^2 \] The MLE systematically underestimates the true population variance by a factor of \(\frac{n-1}{n}\). However, as the sample size \(n \to \infty\): \[ \lim_{n \to \infty} E\left[\hat{\sigma}^2_{\text{MLE}}\right] = \lim_{n \to \infty} \left(1 - \frac{1}{n}\right)\sigma^2 = \sigma^2 \] Thus, \(\hat{\sigma}^2_{\text{MLE}}\) is asymptotically unbiased, despite having finite-sample bias.

3. Non-Regular Boundary Estimation: Uniform Distribution \(\text{Uniform}(0, \theta)\)

Calculus-based optimization (setting \(\frac{\partial\ell}{\partial\theta} = 0\)) relies on the critical assumption that the maximum occurs at an interior point where the log-likelihood is differentiable. When the support of the distribution depends on the unknown parameter, this method fails completely.

Derivation: Uniform\((0, \theta)\) Boundary MLE Let \(X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \text{Uniform}(0, \theta)\), where \(\theta > 0\) is unknown.

The PDF must be written explicitly using the indicator function \(\mathbb{I}\):

\[ f(x_i; \theta) = \frac{1}{\theta} \mathbb{I}(0 \le x_i \le \theta) \] The joint likelihood is: \[ L(\theta) = \prod_{i=1}^n \frac{1}{\theta} \mathbb{I}(0 \le x_i \le \theta) = \frac{1}{\theta^n} \prod_{i=1}^n \mathbb{I}(0 \le x_i \le \theta) \] Notice that \(\mathbb{I}(0 \le x_i \le \theta) = 1\) for all \(i\) if and only if \(\min(x_i) \ge 0\) and \(\max(x_i) \le \theta\). Denoting the maximum order statistic as \(X_{(n)} = \max(X_1, \dots, X_n)\): \[ L(\theta) = \begin{cases} \frac{1}{\theta^n}, & \text{if } \theta \ge X_{(n)} \\ 0, & \text{if } \theta < X_{(n)} \end{cases} \] Analysis: For all \(\theta \ge X_{(n)}\), the function \(L(\theta) = \theta^{-n}\) is strictly decreasing as \(\theta\) increases. Setting the derivative \(\frac{dL}{d\theta} = -n\theta^{-n-1} = 0\) yields no valid real solution!

The function achieves its supremum at the lowest permissible value of \(\theta\), which is precisely at the boundary: \[ \hat{\theta}_{\text{MLE}} = X_{(n)} = \max(X_1, X_2, \dots, X_n) \]

4. The Invariance Property of Maximum Likelihood Estimators

The Motivating Dilemma: Unbiasedness is NOT Invariant! (Slide 6.2)

Suppose we have a random sample from a distribution with mean \(\mu\) and variance \(\sigma^2\).

  • An unbiased estimator of \(\mu\) is the sample mean \(\bar{X}\): \(E[\bar{X}] = \mu\).
  • If we wish to estimate \(\mu^2\), should we use \(\bar{X}^2\)? \[ E\left[\bar{X}^2\right] = \text{Var}(\bar{X}) + \left(E[\bar{X}]\right)^2 = \frac{\sigma^2}{n} + \mu^2 \neq \mu^2 \] No! \(\bar{X}^2\) is a biased estimator of \(\mu^2\). Unbiasedness is never generally preserved under nonlinear transformations.

In sharp contrast, the Maximum Likelihood framework possesses the Invariance Property: whatever transformation we apply to the parameter, the MLE of the transformed parameter is simply the transformation applied to the original MLE!

Theorem 4.1 (Invariance Property of Maximum Likelihood Estimators) Let \(\hat{\theta}\) be the MLE of \(\theta\). If \(\tau = g(\theta)\) is any function of \(\theta\), then the MLE of \(\tau\) is: \[ \hat{\tau} = g(\hat{\theta}) \]
Slide 6.2 Example: Reparameterizing the Exponential Distribution

Let \(X_1, \dots, X_n \overset{\text{i.i.d.}}{\sim} \text{Exp}(\text{rate} = \lambda)\). The MLE for \(\lambda\) is \(\hat{\lambda} = \frac{1}{\bar{X}}\). Suppose we want to find the MLE of \(\tau = \lambda^2\).

Method 1: Direct Reparameterization. Since \(\tau = \lambda^2 \implies \lambda = \sqrt{\tau}\), the PDF is: \[ f(x; \tau) = \sqrt{\tau} e^{-\sqrt{\tau} x} \mathbb{I}_{[0, \infty)}(x) \] Computing the likelihood and log-likelihood in terms of \(\tau\): \[ \ell(\tau) = \frac{n}{2}\ln \tau - \sqrt{\tau} \sum_{i=1}^n x_i \] Differentiating with respect to \(\tau\): \[ \frac{d\ell}{d\tau} = \frac{n}{2\tau} - \frac{1}{2\sqrt{\tau}}\sum_{i=1}^n x_i = 0 \implies \frac{n}{\sqrt{\tau}} = \sum_{i=1}^n x_i \implies \hat{\tau} = \frac{n^2}{\left(\sum_{i=1}^n X_i\right)^2} = \frac{1}{\bar{X}^2} \] Method 2: By Invariance. We immediately write: \[ \hat{\tau} = \hat{\lambda}^2 = \left(\frac{1}{\bar{X}}\right)^2 = \frac{1}{\bar{X}^2} \] Both methods yield the exact same estimator. Invariance guarantees we never need to redo the calculus!

5. Proof of the Invariance Property for Bijective Transformations

Proof (One-to-One Case) Suppose \(g: \Theta \to \Omega\) is a bijection (one-to-one and onto), so the inverse function \(g^{-1}: \Omega \to \Theta\) exists and is unique. Then \(\theta = g^{-1}(\tau)\).

Define the likelihood function in terms of the new parameter \(\tau \in \Omega\):

\[ L^*(\tau; \mathbf{x}) = L(g^{-1}(\tau); \mathbf{x}) \] By definition of \(\hat{\theta}_{\text{MLE}}\), for all \(\theta \in \Theta\): \[ L(\theta; \mathbf{x}) \le L(\hat{\theta}_{\text{MLE}}; \mathbf{x}) \] Substituting \(\theta = g^{-1}(\tau)\): \[ L^*(\tau; \mathbf{x}) = L(g^{-1}(\tau); \mathbf{x}) \le L(\hat{\theta}_{\text{MLE}}; \mathbf{x}) \] Now evaluate \(L^*\) at the candidate point \(\hat{\tau} = g(\hat{\theta}_{\text{MLE}})\): \[ L^*(g(\hat{\theta}_{\text{MLE}}); \mathbf{x}) = L(g^{-1}(g(\hat{\theta}_{\text{MLE}})); \mathbf{x}) = L(\hat{\theta}_{\text{MLE}}; \mathbf{x}) \] Therefore, for all \(\tau \in \Omega\): \[ L^*(\tau; \mathbf{x}) \le L^*(\hat{\tau}; \mathbf{x}) \] Hence, \(\hat{\tau}_{\text{MLE}} = g(\hat{\theta}_{\text{MLE}})\). \(\blacksquare\)

Remark on Non-Invertible Transformations: When \(g\) is many-to-one, the theorem still holds by defining the profile likelihood: \[ L^*(\tau) = \sup_{\{\theta: g(\theta) = \tau\}} L(\theta) \]

6. Practical Applications: Odds, Tail Probabilities & Functions of Parameters

Example 6.1 (Normal Standard Deviation) For a Gaussian distribution, the MLE for variance is \(\hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2\). By invariance, the MLE for standard deviation \(\sigma = \sqrt{\sigma^2}\) is immediately: \[ \hat{\sigma}_{\text{MLE}} = \sqrt{\hat{\sigma}^2_{\text{MLE}}} = \sqrt{\frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2} \] No new differentiation or optimization is required!
Example 6.2 (Poisson Zero-Truncated Probability) Let \(X_1, \dots, X_n \sim \text{Poisson}(\lambda)\). The MLE for \(\lambda\) is \(\hat{\lambda} = \bar{X}\).
Suppose we wish to estimate the probability that an observation is strictly positive: \[ \tau = P(X_i > 0) = 1 - P(X_i = 0) = 1 - e^{-\lambda} \] By the invariance property, the MLE of \(\tau\) is directly: \[ \hat{\tau}_{\text{MLE}} = 1 - e^{-\hat{\lambda}} = 1 - e^{-\bar{X}} \] This plug-in estimator is automatically the most statistically efficient estimator for \(\tau\).
Summary Takeaway The invariance property guarantees that once an MLE is found, any function of the parameter can be estimated by plug-in. However, how do we prove that an estimator is the "best" possible estimator? In Lecture 07, we establish the theoretical limit of estimation precision: the Cramér-Rao Lower Bound (CRLB).
